# 订单反馈与售后记录 / Order feedback and aftercare records

2026-10-30。落实P01-F16/T16的订单客服入口和自助恢复，并为P01-F12的平台错误核实提供入口。保持58项需求、52项P0、三路线、10套官方风格/至少14变体及C「柚子创作社」设计。本轮只运行定向检查及当前构建，不等待全面测试绿灯。

## 用户流程 / User flow

| 编号 | 操作 | 已实现行为 |
| --- | --- | --- |
| 01 | 从订单或领取页打开帮助 | 服务端确认原订单归属后展示反馈表单，公共帮助文章独立加载。 |
| 02 | 选择问题类型 | 付款、制作、商品/文字错误、保存、退款、其他，共六类。平台制作错误提示核实纠错，不消耗一次自选修改；提交本身不会触发退款或修复。 |
| 03 | 说明问题与证明图片 | 说明1至2000字，可选最多5张JPG/PNG，每张最多10MB；选图后可移除。使用私有SUPPORT_EVIDENCE上传与既有真实文件验证。 |
| 04 | 提交或恢复 | 一个提交实例冻结原订单、分类、说明与照片组；未知提交结果保留内容并锁定编辑。重试原上传授权、原完整文件及原工单键，避免重复上传或建单。 |
| 05 | 查看反馈记录 | 帮助页读取本人游标分页记录，支持这笔订单/全部订单筛选；无订单参数时也可查看本账户记录。筛选只处理已加载记录，可继续加载。 |
| 06 | 查询处理状态 | 单独查询原反馈的最新OPEN/PROCESSING/RESOLVED/CLOSED状态，不沿用创建时的旧OPEN回执。关联订单入口用于查询真实退款和素材。 |
| 07 | 离页或换号 | 在异步等待后检查页面和原账户，禁止迟到上传授权继续写入或提交到新账户；返回重新读取本人记录，不自动重发反馈。 |

本地不持久化说明、证明照片字节、上传链接或工单正文。页面内未知提交的原输入只保留在内存；进程重启后应先查询服务端记录，未提交的文字和选图需重新填写。这不是跨进程私有表单草稿功能。

## 接口与责任 / Boundaries

- [共享帮助页面](../../src/shared/ui/help.tsx)负责分类表单、可选图片、原请求继续、本人记录分页/筛选和最新状态。
- [提交控制器](../../src/shared/client/support.ts)负责输入检查、原账户/订单/页面绑定、并发合并、原键重试与响应归属核验。
- [证明上传](../../src/shared/client/evidence.ts)继续使用原授权与完成查询，新增可选页面边界检查；其他授权/举报调用方保持原用途。
- [服务端工单](../../src/api/modules/support.ts)保留原鉴权、幂等和私有正文，附件必须属于本人、READY、未过期且用途为SUPPORT_EVIDENCE；其他用途不能混用。
- 沿用既有createSupportTicket/listSupportTickets/getSupportTicket，不新增契约或支付接口。买家接口只返回编号、关联订单、分类、状态和更新时间，不返回私有说明或附件地址。

创建反馈不会发起新订单、支付、退款、受限修改或模型调用，也不会占用成功修改次数。这里只提供原订单问题入口和当前状态读取；运营分派/回复、完整工单处理状态机、平台免费纠错执行和真实退款仍需各自实现与验证，不能用“已受理”宣称售后完成。

## 验证与交付 / Verification and delivery

精确源码、定向结果和初次失败记录见[验证来源](../verification/support-source.json)。原生数据库/API专项使用实际生成的PNG，经过本地上传授权、实际对象写入、文件解码、完成检查和私有关联；不使用客户图片，也不证明云端OSS、宿主授权或真实客服处理。状态变化用显式数据库夹具产生，不冒充运营工作流。

[页面录制](../media/support/README.md)使用真实共享页面及显式合成上传/状态/回执丢失。脚本关闭本次浏览器、页面和独立预览服务。初次API夹具缺少getOrder所需字段，响应契约校验拒绝；修正夹具后重新执行定向检查，不放宽响应校验。

本轮首次分组启动在API/Worker就绪前结束，仅观察到回收器及媒体维护就绪；延迟的具体根因未确认，见[原失败记录](../verification/support-startup-initial.json)。[本地启动器](../../scripts/delivery/start.ts)现使用[单次经过时间预算](../../scripts/delivery/readiness.ts)：页面30秒、后端45秒，每次探测只拿剩余时间且不延长原预算，停止或过期后的成功不接受。后端必须同时具备API健康及Worker/回收器/媒体维护三份就绪事件。仅调整本地启动观察与失败回收，不改变任何订单、费用、权限、业务截止或生产准入门禁。

The shared help screen offers six categories, optional private evidence images, original-request recovery, paged owned history and current status queries. Native API checks upload and validate actual generated PNGs; browser callbacks and staff state transitions are explicit fixtures. Descriptions, photo bytes and private URLs are not persisted on the client. Receiving a ticket does not prove a refund, repair or complete support workflow.

真实Codex/模型/支付/OSS/实例隔离、四组真机、原生口播修复、完整社区/运营售后及Plus仍待完成；所有官方方案保持禁售，完整产品/生产准入/云端部署保持false。原预算、期限、UNKNOWN与独立核验规则不变。
