后续状态 / Subsequent scope: [声音文件验收与封存](原生声音文件验收与审查封存-v1.0.md)已补齐内部技术QC，以下未接入QC描述为本历史阶段或完整听音验收；独立听音/最终语义双复核/有声交付和公开订单门禁仍保留。Technical file QC was connected later; final listening/review/delivery remain closed.

## 1. 本次交付与边界

内部 `ORDER/PRODUCTION → ORDER/POST` 已接入两条生成路线：`PER_SHOT_AI` 和 `REFERENCE_FILM`。实际生成视频的原始声音按完整时间轴组装，受控后期角色调用原任务转写，再使用实际字级时间码完成字幕和许可配乐。恢复使用原生成/转写购买和已登记的后期回执。

这不是完整有声产品准入：公开报价和创建订单继续以 `NATIVE_AUDIO_NOT_ADMITTED` 阻断；原生声音 QC 策略不被当前静音 QC 接受；独立听音、语义/口型核验、最终有声双复核及交付尚未接通。所有官方方案继续 `sale_enabled=false`。只有一个主人物/声音绑定，不证明官方多人讲解变体已实现。

**English scope:** Both private generated ORDER routes now connect production, lossless native-track assembly, once-only durable ASR and caption/music POST through scoped HTTPS/stdio/MCP tools. Public audio orders, listening/QC and delivery remain closed. Native database/media/protocol tests use synthetic model, authorization, transcription, usage and isolation responses; they do not admit real services or multi-presenter quality.

证据按实际范围记录：独立后期内核回执仍保留 `order_pipeline_connected=false` 和 `semantic_review=NOT_PERFORMED`，不会被包装器改写。外层 `NativeOrderAudio` 记录原订单声音合同、组装证明和原成功 ASR/后期绑定；实现索引的 `production_post_connected=true` 仅表示内部制作/后期已经连接，完整有声订单产线仍未准入。

## 2. 用户使用逻辑与内部执行

最终产品继续以支付宝/抖音小程序为入口：拍照 → 多模态商品档案 → 社区预设/官方十套 → 冻结规格和报价 → 制作/后期/核验 → 素材列表 → 本人下载/保存相册。无需填写商品信息；Plus 仍是 P1 复杂编辑入口。本次后台接入没有新增面向用户的模型、工具或 ASR 配置表单。

| 编号 | 步骤 | 平台负责的实际行为 |
| --- | --- | --- |
| 01 | 原合同与许可检查 | 校验快照、人物/声音/视频模型组合、原预算/截止、实际配乐字节与授权有效性 |
| 02 | 参考制作和独立商品核验 | 沿用原生成工具、真实 PNG、锚点证据与实例释放规则；未通过不能购买视频 |

## 3. 声音组装与转写副本

`native-audio-assembly.ts` 验证每个实际生成源的 SHA、音轨、30fps 和镜头帧数，按不可变顺序覆盖完整时间轴，拒绝空洞、重叠及来源替换。原音轨解码为 48kHz、双声道、16-bit PCM，以单位增益拼接；无补语音、二次 TTS、归一化或配乐替代。ALAC 中间片重新解码后必须与拼接 PCM 逐字节相同。最终 POST 编码为 AAC，不向用户交付 ALAC 中间片。

ASR 使用独立私有单声道 WAV。未带新策略的历史冻结合同保持原行为：左右 PCM 必须完全相同。可选冻结 `SpeechContract.channel_policy = MEAN_STEREO_V1` 时，每个采样为 `Math.round((left + right) / 2)`，两边系数均为 0.5，不选弃某个声道、不放大音量。

导出前比较单声道能量与原双声道平均能量，原静音或比例低于 0.1 时以 `ASR_STEREO_CANCELLATION` 拒绝，且不购买 ASR。证明记录原/副本 PCM SHA、样本数、固定系数、能量比（六位小数）及策略版本 `YPCC-ASR-MONO-DERIVATIVE-1`；原 WAV SHA 和该证明共同进入原请求输入摘要。策略参与模型能力和声音合同摘要，恢复时重新核对。交付后期始终使用原双声道，不使用该 WAV 副本替代原声音。能量检查只发现明显相消，不代表语义、立体声内容或识别质量验收。

## 4. 唯一原购买、原回执与恢复

原 ASR 网关仍使用持久意图、费用预留、发送标记、任务 ID、追加式原始提交/查询/结果回执及唯一整轨请求约束。一单只有一次完整整轨 ASR 额度，重复工具调用和实例恢复不能重置额度；不能逐镜重复转写，也不能将计划台词直接作为识别结果。

提交 ACK 丢失、费用未知或供应商仍在运行时，只进入原任务等待/恢复，不能购买第二次。只有与原订单、商品、主人、POST 快照和原截止一致的 `SUCCEEDED` 任务，且原费用已 `SETTLED`、原转写文件仍有效并匹配 SHA，才能用于 POST。验证读取原回执，不发起新的识别或续签供应商地址。

后期已生成文件但数据库提交回滚时，保留原媒体操作清单和私有文件。下一次重放原清单、核对真实字节及授权后提交，不重新渲染、不再次推理、不再次 ASR。截止、取消、租约接管和资源撤销继续阻断，临时原生处理目录在退出时清理。

## 5. 配乐资源与权限

许可记录可冻结 `audio_media`：`object_key / sha256 / size_bytes / mime_type`。仅 MUSIC 可携带该结构，键限定 `licensed-resources/<resource_version_id>/<file>`，摘要须等于原资源绑定。资源属于平台许可库，不是买家原照片或公共下载地址；缺失/替换实际配乐会在参考及视频购买前拒绝。

不带媒体字段的历史授权合同仍可解析，但选择配乐的实际执行必须具备真实媒体绑定。授权正文和版本、资源摘要、原费率与一次性预付分摊保持不可变/只能退役；该分摊是内部账务，不是对外采购付款凭证。原声保持单位增益，仅配乐按冻结音量、duck 和循环规则处理；未许可配乐不能自动换成其他音源。

工具只返回逻辑 ID、原转写结果及摘要，不允许角色传 URL、任意路径、模型、费率、新台词或伪造时间码。`transcribe_actual_audio` 仅授予本订单 POST；原图/无声路线不会获得新能力。组件预算、五角色/工具上限、原时间轴和截止没有放宽。
