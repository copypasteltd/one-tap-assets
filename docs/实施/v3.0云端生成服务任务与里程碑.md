# 一品成片：v3.0云端生成服务任务与里程碑

2026-10-27｜对应需求v3.0/F01—F50。以下均为待实现任务；只读仓库研究、配方提取和文档核验已完成，不代表任务已实现。主入口为 [PRD](../01-产品需求PRD.md)、[验收计划](../05-验收测试与实施计划.md) 与 [方案变体规格](../设计/方案组件与执行变体规格-v3.0.md)。

## 1. 范围与排期依据

当前完整P0为双小程序、强制多模态与商品锁、10套官方/14变体、三条云端产线、声音/字幕/商品卡/封面后期、整包QC、渠道交易/退款、相册恢复、基础社区与生产恢复。P1为Plus/绑定/多语言/A-B，P2为高级条件化方案与授权外部发布。

历史 [v2.1任务估算](开发任务与评估修订-2026-10-27.md) 的69–99人日/两人8–12周不含本次新增生成式核心；不能简单把391配方视为现成模板来缩短，也不能将模型调用等待等同于全部研发成本。本版工期在G0真实能力/成本/失败实验后重估，输出各工作包人日、并行依赖、外部等待与人员能力假设。

本轮只更新需求和设计配置，没有开通供应商、创建付费云资源或要求买家参与手工制作。后续实际模型/资源/发布行动在相应配置与授权具备后实施；本地一律Windows原生，不启动Docker/WSL/虚拟机。

## 3. 关键路径与阶段门槛

关键路径：能力/权利 → 数据合同/商品锁 → 计划/报价 → 参考帧 → 逐镜/整片 → 统一后期/QC → 交易恢复/小程序保存 → 官方14变体/社区 → 全量验收。身份/私有上传与宿主验证可在合同冻结后独立推进；不能在缺少声音/参考能力验证时先承诺全部人物效果。

| 阶段 | 必须拿到的可审查结果 | 尚不能声称的结果 |
| --- | --- | --- |
| G0 能力实验 | 四类AI服务和原图原型、实际模型/费率、参考/声音/商品缺陷、质量阈值、双端能力记录与v3估算 | 全模型通用、上游样片即本产品效果 |
| G1 无界面依赖纵向执行 | API/Worker从照片到全包，实际供应商任务/后期/QC/manifest可追溯 | 一条好片即官方14变体完成 |
| G2 双端与交易可靠性 | 四类真机保存、支付/退款/UNKNOWN与崩溃恢复、预算/截止失败策略 | 内测范围等于正式全量上线 |
| G3 内容与社区准入 | 10套/14变体样例、≥420整包、识别/高危负例集、两作者/两买家社区链路 | 391条来源全部可售 |
| G4 完整v3发布 | 44项P0与适用共用验收、合法渠道/域名/审核、容量/成本/运维 | 未获准端或P1/P2自动完成 |

测试中的人工标注/听辨/平台发布审核可以存在，正常订单不引入逐单人工制作。为排障代做须单独标记，不计自动完成率。

## 4. 重估必须补齐的数据

重估基于每条产线至少覆盖正常和失败的实际样本：图片/参考数、视频时长、声音、模型/检测调用成本、队列/生成/后期p50/p95、重做概率、内存/CPU/存储下载、支持和退款。独立列出可复用代码的迁移/许可/跨平台代价，不按源码规模推算复用率。

完整排期还须列人员是否具备双小程序、FFmpeg、生成式模型与支付经验，设计/标注/权利审核/运营投入以及外部等待。G0未完成前不恢复旧版周数或用“增加几天接API”承诺完整v3。
