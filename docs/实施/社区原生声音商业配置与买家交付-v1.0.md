# 社区原生声音商业配置与买家交付 v1.0

本增补衔接 P01-F04、F07、F21、F25、F38—F40、F51—F58：社区原生声音样例完成后，平台可以为同一社区版本准备有声商业配置，买家使用既有小程序入口完成规划、报价、付款、制作、交叉核验和私有领取。普通客户仍只需拍照并选方案，默认人物和声音由平台配置提供。

实现入口为 [平台商业配置](../../src/api/modules/community-commercial.ts)、[声音商业绑定](../../src/api/modules/community-native.ts) 和既有原声订单管线。本轮源码、实际结果及早期尝试以 [准确来源](../verification/community-native-source.json) 为准。样例制作、公开样例许可与买家付费制作分别保留原作用域和账本，不相互授予权利。

## 1. 使用流程

1. 作者沿用受控社区编辑器、原生声音样例及既有申请/审核/发布流程，不能上传可执行代码、指定任意服务地址或直接设置成交价。
2. 平台为已发布的社区执行版本选择一组已准入的默认人物、原生声音及其视频模型组合。商业模型、价格和原预算来自已准入官方蓝本，实际资源必须与该蓝本的商业资源一致。
3. 平台一次性冻结声音商业配置，版本继续为 `NOT_EVALUATED`、`sale_enabled=false`。社区版本的完整准入和开售仍通过原管理流程独立完成，不能复制官方准入结论。
4. 买家在支付宝或抖音小程序拍照、选社区方案。内容规划已收到冻结人物和声音，只能在照片证据范围内完善台词。工具及最终计划都拒绝换人换声。
5. 报价重新校验原模型、费率、人物、许可、资源和预算，并按实际分镜/参考数量计算完整成本。用户确认清单后主动付款，原生视频、转写字幕、整轨听音、新事实/风格双复核和事务交付继续走原订单链路。
6. 领取图片、视频和文案，保存相册。交付后释放实例，作者不能读取买家的照片、订单或成品。停止新销售不会改写已经付款的原合同。

## 2. 平台配置命令

无声配置继续使用原五个参数。有声配置额外传入人物版本和声音编号：

```powershell
pnpm community:prepare <variant-id> <version> <expected-revision> <operator> <reason> <character-version-id> <native-voice-id>
```

这是平台运维入口，没有新增作者权限或公开 HTTP 操作。缺少默认声音、人物/视频组合不匹配、许可不足、未使用资源或原预算不足都会在推理和生成消费前拒绝。配置不调用模型、不创建订单、不预留预算、不形成真实准入证据，也不会启用销售。

## 3. 冻结内容与原预算

`commercial_binding.native_audio` 使用 `YPCC-COMMUNITY-NATIVE-1`，保留社区源摘要、原人物声音组合、完整商业许可、资源绑定、四个独立模型及其协议/费率摘要、原价格、原预算、修复额度和最早到期时间。

| 编号 | 绑定 | 验证位置 |
| --- | --- | --- |
| NC01 | 默认人物、原生声音与视频模型 | 平台配置、规划工具、报价、原订单声音合同 |
| NC02 | `ORDER` 商业声音授权 | 配置和每次规划重查，报价及付款后沿用原许可门禁 |
| NC03 | 图片、视频、ASR、独立听音四模型 | 原登记、协议、能力摘要与费率版本一致；撤回或变更阻断新规划 |
| NC04 | 字体、人物、声音及可选配乐 | 蓝本资源与实际使用集合一致；社区声明不得夹带未使用资源 |
| NC05 | 价格与原制作/修复预算 | 配置一次冻结；实际计划报价重新核算整包费用，不追加额度 |
| NC06 | 原计划与商业配置摘要 | 规划输入、MCP 校验、持久结果、报价保持同一冻结人物声音 |
| NC07 | 有效期 | 以模型、人物及商业许可的最早到期限制配置和报价；过期阻断新使用 |

配置时的 `minimum_cost_micro` 是不可避免的成本下界，包含原 Agent/售后、修复、最少图片/视频、商业许可、转写与完整听音包；它不是完整分镜成本的准入报告。真实分镜、参考和全部生成数量仍在报价前按原 `generationCostCeiling` 核算，超出原预算拒绝报价。

`SAMPLE` 许可的 `PUBLIC_ADVERTISING_SAMPLE` / `PREPAID_PLATFORM_SAMPLE_ALLOCATION` 不能替代 `ORDER` 的 `GENERATED_COMMERCIAL_AD` / `PREPAID_ORDER_ALLOCATION`。公开样例通过不等于买家制作获授权。无声版本也不能携带新声音配置而静默升级。

## 4. 不可变性与恢复

沿用迁移 031 对整个 `commercial_binding`、源、模型、资源、价格及预算的不可变约束，声音绑定作为其内部字段一同保护；不修改原迁移，也不增加旧订单权益。商业配置变更要求新发布版本。

规划冻结完整声音配置摘要，内容角色仅得到对应的人物声音候选。工具每次校验当前原登记和许可；变更、撤权或过期在推理前或结果提交前阻断。报价校验规划保留的配置与当前不可变配置一致，并把实际声音能力冻结到原订单合同和快照。

已经付款的订单继续使用原声音、模型、费用、角色、Token、工具、修复次数及截止。UNKNOWN 仍只查询原任务、消费原回执，不重购、不替换声音、不重置预算或截止。声音本身需要更换时使用新的报价，不伪装为原订单小修改。

## 5. 本轮验证与交付边界

只执行与本增补相关的原生数据库和媒体专项、类型检查及当前服务端/网页构建，不执行全面测试或将全绿作为打包前提。两条有声社区买家路线应覆盖实际规划、报价、付款事实、PNG/MP4、原声/字幕、独立听音、双复核、下载和实例释放；缺默认声音、SAMPLE-only 许可、预算不足、模型变化、许可撤回及换声必须阻断。

专项中的社区发布和准入、付款事实、商品/模型语义、中文转写、听音结论、人物/声音许可、计价与进程身份均为明确的合成夹具。原生 PostgreSQL、HTTPS/MCP、媒体文件处理及下载是真实操作；提示音不证明真实中文听感，不证明完整社区商业准入或生产隔离。三项原有无声社区检查按原断言通过。一项原有官方有声买家用例在原240秒限时内超时，原因未确认；未提高限时或削弱断言，原报告独立留存。后续两条新增社区有声买家整链及两项新门禁在原限时内通过，不将它们视作旧用例已通过。

本轮不新增界面布局；现有截图、录屏、GIF、原生样例媒体和方案 C 设计原件保留原字节及原版本，不标为本轮真机录制。双语说明、更新记录、源码包与专项报告同步到仓库。

真实服务、完整官方/社区准入、生产实例隔离、双小程序真机、Plus、云部署和完整58项验收继续独立待办。销售和真实服务保持关闭，完整产品/生产/云端标记保持 false。
