# 社区审核工作台与原申请证据核对 v1.0

2026-10-30。对应 P01-F14、F28、F31 的运营审核入口，沿用 C「柚子创作社」视觉。支付宝、抖音小程序仍是客户主入口；本工作台供工作人员核对社区作者提交的方案，不替代面向客户的 Plus 进阶制作端。

本轮按用户要求快速收口，交付可运行源码、当前服务端与预览构建、实际浏览器截图/录制；验证仅覆盖本轮关键功能。[准确来源](../verification/review-console-source.json)、[本轮状态](../guides/STATUS.md)、[启动与打包](../delivery/README.md)。完整 58 项需求、真实服务准入和云部署继续独立跟踪。

## 使用流程

1. 启动本地原生 API 和后台任务，打开 API 同源的 `/ops/review`。静态登录页面不包含作者私有资料。
2. 输入独立分配的管理令牌。`moderator:review` 读取申请、原方案、许可全文、选定样例和授权证明；发布另外需要 `moderator:publish`。买家会话不能进入管理接口。
3. 按状态查询申请，打开原申请版本。查看风格、制作规格、许可、作者权利声明及证明。文件由受控管理接口读取，前后端核对归属、长度、SHA-256 和 PNG/MP4 签名，随后在页面内显示图片或播放视频。
4. 查看全部样例与证明，逐项确认权利，再填写处理说明。可以批准、退回补充或拒绝。前端的核对提示辅助工作人员，服务端仍独立重验原申请和审核证据。
5. 批准后等待已有后台任务准备独立公开副本；刷新申请看到副本就绪后，再按独立权限发布。发布成功仍为 `sale_enabled=false`，制作能力准入、平台定价和开售继续独立处理。
6. 如写操作已提交但回执丢失，页面保留原申请、版本、请求正文与幂等编号。“继续确认原操作”查询/重试同一操作，期间禁止切换申请或新增写操作。确定的客户端错误可刷新修正，未知状态不创建新操作。
7. 退出时清空当前账户、资料和媒体预览，释放 Blob URL；所有权威状态从数据库恢复。

## 本轮新增接口

均位于 `/v1/internal/p01`，经过原管理鉴权、响应校验、事务、访问审计和禁止缓存处理。

| 方法 | 路径 | 返回内容 | 权限 |
| --- | --- | --- | --- |
| GET | `/publications` | 既有申请队列，新增 `state` 筛选及绑定筛选条件的游标 | `moderator:review` |
| GET | `/publications/{publication_id}` | 原申请配置、许可全文、选定样例和权利声明 | `moderator:review` |
| GET | `/publications/{publication_id}/samples/{sample_id}/media/{item_id}` | 原选定独立样例的受控 PNG/MP4 实际字节 | `moderator:review` |
| GET | `/publications/{publication_id}/rights/{rights_record_id}/evidence/{asset_id}` | 原选定权利声明的证明图片 | `moderator:review` |

批准、退回、拒绝和发布复用已有写接口。业务接口仍为 77 个；管理操作由 32 增至 35 个。同步更新 OpenAPI、管理目录、生成器和 TypeScript 类型，不新增数据库迁移。

## 读取与权限约束

只从原发布申请的冻结请求推导样例、权利声明和证明，不接受任意对象路径或外部 URL。每次核对同租户、同作者、原商品仍存活、选定样例仍 READY、原私有对象仍登记有效且未申请删除。样例读取继续执行既有完整制作证据检查，生产路径没有新增测试绕过。

跨申请的样例、权利或证明返回拒绝；作者商品删除、到期、资料撤回或脱敏后，只保留申请状态元信息，不继续返回原配置、声明和私有媒体。实际文件与原摘要不一致时停止读取。资料 DTO 不暴露对象路径、买家成品或原商品照片。

单个审核媒体上限为 125 MB，经 JSON Base64 传输；不采用外部直链。适合当前单文件核对，较大样例的流式传输和更细颗粒的媒体审核体验留待后续优化。

令牌只存在页面内存；请求不携带买家 Cookie、不跟随重定向、不缓存。切换账户会取消原请求并丢弃迟到响应。关闭预览、切换申请、退出或卸载均释放已创建的媒体地址。

## 配置与启动

沿用 `MANAGEMENT_TOKENS_JSON` 的原配置：每项包含工作人员 `actor`、令牌的 `token_hash` 和最小 `permissions`。只保存令牌摘要，原令牌通过既有可信渠道分配；不得写入仓库或浏览器持久存储。`COMMUNITY_PUBLISHING_ENABLED` 默认关闭，本轮不修改本机私有环境设置。

使用 [交付启动指南](../delivery/README.md) 安装本机 Node、PostgreSQL 与 FFmpeg，执行 `pnpm delivery:build --skip-mini` 生成本轮服务端和预览构建，再按指南启动。服务端负责 `/ops/review` 页面和同源静态资源。测试录制脚本为 `scripts/record-review-desk.ts`，仅针对隔离测试库准备明确标注的合成资料，不是生产数据初始化或真实准入程序。

## 验证与证据边界

| 编号 | 验证内容 | 范围 |
| --- | --- | --- |
| 01 | 审核客户端 6 项 | 原键恢复、冲突拒绝、回执绑定、实际字节摘要、跨账户迟到响应 |
| 02 | 原生 API 3 项 | 权限隔离、原申请归属、删除/变更拒绝、图片/视频、筛选游标、独立审核和发布幂等 |
| 03 | 浏览器关键流程 | 实际页面、PNG/MP4 解码、权利核对、已提交回执丢失后同键恢复、公开副本和发布、退出释放 |
| 04 | 构建与启动 | 当前类型检查、服务端、预览、自检和原生启动；小程序重编与全面测试不列为本轮前置 |

浏览器使用实际本地 HTTP、PostgreSQL、上传、PNG、FFmpeg MP4、私有读取和公开副本。作者身份、商品档案、权利声明、许可和 READY/QC 来源是显式合成夹具，不证明真实作者授权、生成质量、完整 SAMPLE 产线、生产人员身份或生产隔离。录制只能支持上述流程结论。

先前类型诊断、失败单元检查、录制准备失败和其源码来源完整保留；历史验证、原 93 份媒体、C 冻结 25 文件及设计归档不覆盖。新媒体见 [审核工作台录制](../media/review-desk/README.md)。本轮使用的浏览器及自有测试服务结束后关闭。
