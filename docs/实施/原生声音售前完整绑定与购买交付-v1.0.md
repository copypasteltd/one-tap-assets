# 原生声音售前完整绑定与购买交付 v1.0

2026-10-30。本轮按主要功能快速收口，将已有内部原生声音制作、后期、独立听音及双复核接到买家的原方案、报价和订单。此前内部链路可运行，而公开报价/下单固定拒绝有声方案；现在仅允许具备完整冻结绑定的新报价进入购买。当前真实服务未开放，所有方案仍禁售。

## 用户交互与范围

支付宝小程序、抖音小程序继续使用已有的“拍照 → 自动识别 → 选择社区预设/规格 → 核对清单和价格 → 购买 → 查看制作 → 领取/保存相册”流程。用户不填写商品属性表；多模态识别和 CONTENT 规划负责商品特征、脚本与镜头。此次不增加界面、不改 C 定型设计，也不增加声音选择表单。

两条生成路线可使用方案原本已批准的人物和原生声音：逐镜头生成 `PER_SHOT_AI`、参考整片 `REFERENCE_FILM`。成品保留原生音轨，禁止以第二次 TTS 替换；字幕依照实际音频转写及时间戳，配乐只能使用冻结许可资源或按原合同保持无配乐。原图排版和已有无声购买路线沿用原规则。

## 售前冻结

`src/worker/audio/commerce.ts` 新增私有 `YPCC-NATIVE-SALE-1` 绑定，进入原报价合同摘要和后续订单快照。绑定源方案、规划摘要、完整声音合同、独立听音合同、四类模型协议、Codex 合同、售后条款、原预算和完整费用上界。它不是商用准入证明，也不改变方案的销售状态。

生成、ASR、独立听音、Codex 及人物能力的最早到期时间限制报价有效期，且报价最多有效 15 分钟。下单再次核对原绑定和当前能力，不静默替换供应商、人物、声音、模型、费率或风格。

| 编号 | 必要条件 | 缺失时处理 |
| --- | --- | --- |
| 01 | 已完成原 CONTENT 规划、可信风格和可销售规格 | 拒绝报价 |
| 02 | 唯一且已准入的图片、原生视频、ASR、独立听音协议 | 拒绝报价/下单 |
| 03 | 原人物/声音许可、字体及可选配乐有效，哈希对应 | 拒绝报价/下单 |
| 04 | 已启用交易、Codex、生成、ASR 和独立听音服务 | 拒绝报价/下单 |
| 05 | 私有 OSS HTTPS 签名读取配置，域名在原 ASR 输入许可内 | 拒绝报价/下单 |
| 06 | 原 Codex 视觉复核、角色、Token 和工具上限足够 | 拒绝报价 |
| 07 | 原预算覆盖全部制作和后续授权费用上界 | 拒绝报价 |

私有存储检查验证配置和域名；真实 OSS 网络、凭证有效性和供应商端实际读取仍须环境联调，不以配置检查冒充云端验收。

## 完整费用与支付

`generationCostCeiling` 统一计算图片、视频、Agent、受限修改、修复、人物/声音/配乐分摊、ASR，以及独立听音每包上限乘原包数。修复桶沿用原预留，不增加额外额度。此前分别检查的生成和听音部分费用，现在还必须共同落在同一个原总预算内；全部计算使用整数。

支付仍由既有渠道验签和主动查单形成 `VerifiedPayment`，本模块不接收客户端自报已付款。原支付事实和唯一账本先入库；付款确认时若原人物/声音许可或新声音报价绑定的能力登记已撤回/到期，则不创建制作阶段，沿原订单申请一次退款。重复支付回执返回同一个结果，不重记款、不新建退款。

已消费报价的重复下单请求仍返回原订单，后续停售不会把同一请求变成新购买。新销售检查与已付款订单的冻结执行分别处理。

## 制作与交付

原订单按 PRODUCTION → POST → QC → REVIEW_FACTS → REVIEW_STYLE → DELIVER 执行；参考素材独立核验在付费视频生成前完成。实际音视频和原转写回执封存后，独立听音绑定同一包；事实和风格由新角色分别复核，提交时重验原文件、授权、费用及回执，最后发布本人私有下载链接。交付后实例释放。

UNKNOWN 查询原供应商任务和原凭证，不重购；重试、售后和故障恢复不能刷新预算、次数、Token、工具配额、角色额度或绝对截止。未带新售前绑定的历史内部合同继续拒绝公开下单，不自动升级历史报价或售后权益。没有新增数据库迁移；原 1–31 迁移保持不变。

## 本轮验证与准确边界

准确来源、所选用例和初次失败记录见 [声音购买专项](../verification/native-sale-source.json) 和 [尝试记录](../verification/native-sale-attempts.json)。只进行与本轮变化直接相关的验证以及类型、服务端/网页构建和原生启动检查，不运行全面测试，不要求全面绿灯。

专项使用真实原生 PostgreSQL、HTTPS/stdio/MCP、PNG/MP4/ALAC/AAC 文件、实际后期和私有下载。支付事件、授权、模型语义、识别文本、听音结果、用量以及角色身份均为合成夹具。售前 OSS 配置为合成数据；付款后测试使用本地对象字节与模拟签名读取传输，明确不证明真实 OSS。测试音频为两秒提示音，不证明真实中文声音质量或听音正确性，也不证明生产隔离。

真实服务、完整官方声音规格、云存储、支付清结算、独立模型听音、受限系统身份/清理、支付宝/抖音真机、完整社区商业准入、资源/有声样例、Plus 和云部署继续待完成。完整产品验收、生产准入、云部署标志保持 false。
