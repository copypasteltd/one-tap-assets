# 生成式社区样例与独立平台额度 v1.0

本轮扩展社区作者现有的样例制作入口：在原图排版之外，接入逐镜头生成和参考整片两种无声路线。样例依然属于作者本人，通过完整制作和独立复核后才可作为发布申请的证据。支付宝、抖音小程序共用现有作者页面和接口；网页预览复用相同组件。C 方案的视觉定型与既有截图保持原版。

## 用户操作与交付

1. 上传本人商品照片，等待多模态识别形成商品档案；复用与该组照片对应的商品使用、样例公开授权。
2. 在社区草稿中选择风格组件和制作规格，保存草稿。系统按所选规格申请样例；默认选择原图规格的体验保留，作者可主动选择生成规格。
3. 样例冻结草稿版本、完整来源、商品档案、照片集、身份锁、风格 Skill、模型协议及费率、平台费用和原截止。无法执行所选路线时明确拒绝，用户可另行选择方案。
4. 内容角色制定完整素材计划。生成路线先制作参考图，交给全新的事实角色对照完整原照片和身份锚点。所有参考图通过后才能购买对应视频。
5. 制作角色调用生成图片和实际视频，按计划排版、拼接；后期角色处理真实文件。图片和视频全部帧保留可见的“AI 生成”标识。
6. 文件检查核对尺寸、编码、帧数、无声规格、来源和逐帧标识。封存材料包含原照片、参考图、交付图片、视频采样和文案，再由新的事实、风格角色分别复核。
7. 全部证据通过且实例已释放，私有样例进入 `READY`。作者可通过现有私有媒体链接预览和下载。发布时还需许可、公开同意和独立审核；系统制作独立公开副本后，才开放样例展示。

## 路线与阶段

| 路线 | 原素材 | 制作方式 | 角色运行 |
| --- | --- | --- | --- |
| `PHOTO_LAYOUT` | 完整原商品照片 | 原照片排版和无声短片 | 原有五次独立运行 |
| `PER_SHOT_AI` | 原照片、逐镜头参考图 | 逐镜头实际生成视频，按时间线拼接 | 五个制作/复核角色，加一次独立参考核验 |
| `REFERENCE_FILM` | 原照片、整片参考图 | 实际生成连续短片，再按冻结规格整理 | 五个制作/复核角色，加一次独立参考核验 |

七阶段仍为 `SAMPLE → SAMPLE_PRODUCTION → SAMPLE_POST → SAMPLE_QC → SAMPLE_REVIEW_FACTS → SAMPLE_REVIEW_STYLE → SAMPLE_COMPLETE`。参考核验位于制作阶段，先完成并释放其进程，再启动普通制作角色，避免在同一工具消费者内等待另一个角色。最终事实复核使用全新的实例、线程和身份，不能复用参考核验的结论交付成品。

本次样例支持无声路线及平台字体。带人声、配乐或额外第三方资源的样例须等待对应执行器和授权接入；系统不会自动去掉声音或替换资源来制作。既有付费订单的有声制作、修复及售后属于各自原冻结合同。

## 费用、恢复与访问边界

| 编号 | 要求 | 实现约束 |
| --- | --- | --- |
| GS-01 | 样例独立于交易 | 使用 `sample_id`；不创建订单、支付、买家预算或售后权益 |
| GS-02 | 单次费用有界 | 原样例总额度拆为生成上界和推理上界；参考图、成品图、视频次数和费率在申请时冻结 |
| GS-03 | 每日费用共用原平台账户 | 生成与推理均计入 `CODEX_SAMPLE:作者:日期`，不另开可绕过的每日额度 |
| GS-04 | 原生成任务恢复 | 固定样例、制作阶段、节点和请求摘要，保留提交原文、ACK、查询回执及登记文件 |
| GS-05 | 未知费用保留 | `UNKNOWN` 持续占用原预留，禁止重发创建请求；只查原任务、恢复原回执 |
| GS-06 | 停止后财务恢复 | 媒体维护进程独立对账；停止、撤权、到期后不能借对账发布新媒体 |
| GS-07 | 参考核验先于视频 | 全部原照片、参考图、身份锚点和真实视觉输入必须完整；FAIL/UNCERTAIN 禁止购买视频 |
| GS-08 | 成品来源一致 | 每个媒体文件绑定原生成节点、实际哈希、已结算费用和参考核验摘要，POST 保留来源 |
| GS-09 | 实际文件检查 | 本地原生 FFmpeg/Sharp 检查真实 PNG/MP4；逐帧核验 AI 标识；不使用静态图代替生成视频 |
| GS-10 | 完整独立验收 | 最终复核读取原照片、参考图、成品及视频采样；六次运行身份不同且全部释放 |
| GS-11 | 提交时重验 | READY 和发布前重新检查原授权、冻结输入、费用、来源、文件哈希和交付证据 |
| GS-12 | 私有与公开副本隔离 | 作者原样例始终私有；公开授权副本采用现有独立登记、30 天保留、撤回和过期流程 |
| GS-13 | 原授权不可扩张 | 不增加旧样例权益；原人声、工具、角色、Token、次数、原截止和预算不刷新 |
| GS-14 | 冻结绑定不可改 | 迁移 030 增加显式互斥的订单/样例生成范围，以及样例执行、任务归属不可变保护 |

模型下线后仍可核对原已完成文件和费用；发起新购买前必须重新确认原冻结模型登记仍准入。原始回执在费用未决时保留，避免隐私清理抹去账单依据。平台自用、原生运行的约束继续适用，禁止 Docker、WSL 和其他虚拟化环境。
