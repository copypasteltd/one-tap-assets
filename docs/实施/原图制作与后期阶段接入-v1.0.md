# 原图制作与后期阶段接入

2026-10-28｜需求 v3.1 / 开发契约 v1.1｜整体 IN_PROGRESS。

本轮把 PHOTO_LAYOUT 的 PRODUCTION、POST 接入 Worker 与受控 Codex 角色适配器。实际 PNG、原图短片、显式后期和文案已有源码及原生集成证据。角色协议与模型响应使用明确夹具，不能据此声称真实 Codex、生产隔离、正式方案质量或整包交付已经完成。

## 已实现的执行链

1. 报价将规划时的运行准入与订单推理限额复制进私有 FrozenContract.runtime_binding；付款后的 ExecutionSnapshot 继续固定模型/Skill/清单/预算/截止。每角色轮次和整单 token/成本额度沿用原合同。
2. MediaStageService 读取已售合同、不可变照片/档案/身份锁与快照，核验合同和计划摘要，不读取买家最新档案或作者最新方案。
3. PRODUCTION 启动新角色，经已装载的 MCP 调用 render_photo_pack。平台用 Sharp 执行原图版式，用原生 FFmpeg 执行整数帧原图短片，检查实际文件后写私有检查点。
4. 角色调用 inspect_actual_media，取得覆盖全部产物的实际检查回执，再调用 persist_stage_result。结果必须符合现有 AgentStageResult 契约，完整槽位、真实产物和成功工具回执缺一不可。
5. Worker 在当前父阶段租约下核对角色持久结果并提交阶段。角色的自然语言、RPC 成功或自行编造的产物 ID 均不足以推进。
6. POST 依赖 PRODUCTION 成功，先核验原产物 SHA 和实际规格，再执行 PNG 重编码、视频清理元数据/重新编码和 UTF-8 文案文件输出；按原清单重新解码核验，不截断画面凑时长。
7. 后期完整清单继续保持私有。原图无声[QC与封存](文件验收与封存审查包接入-v1.0.md)已补齐；两份独立复核和 DELIVER 未接通，当前不会因此生成对外可领取的 manifest。

原图路线的输入、图像像素和视频来源均可追溯到本单照片。此执行器不生成未知商品视角，不代替 PER_SHOT_AI、REFERENCE_FILM 或原生中文讲解。现有版式对应官方10个 presetId；社区自定义声明式版式的完整解释器仍需继续开发。

## 原始检查点与恢复

media_operations 绑定 tenant/order/stage/phase/input_hash。输入摘要包含执行器版本、原快照、原计划及前置制作产物摘要。每次实际生成有独立 generation 和私有对象前缀，旧代次无法覆盖新代次。

文件先写私有存储；完整回执列出全部产物 ID、槽位、对象键、SHA、实际检测和原图/前置产物来源。随后在工具事务中复核授权与代次，一次写入 artifacts 并将操作标记 READY。中途存储成功、数据库未提交时，可复用原回执并重新验证实际文件；已有 READY 检查点丢失或哈希不符会阻断，不静默重建。

已成功角色与父阶段提交之间崩溃时，接管读取原 SUCCEEDED 角色和结果摘要，不重新启动角色或购买模型。原角色为 FAILED/UNKNOWN 等尚未核对状态时仍保守等待；完整失败后的有界角色恢复、修复调度和孤儿回收仍需继续实现，不能将这类等待称为已经自动修复。

artifacts 的对象键、内容哈希、来源和规格落库后不可更新；保留期限可按交付/隐私生命周期调整。生产和后期中间件都不作为公开成品。

## 权限、费用与检查

- 制作与后期各装载当前角色的主工具、实际媒体检查及结果持久化。模型只提交快照哈希和资产 ID，不提交路径、命令、URL、SQL或凭证。
- 推理出口同时限制整单请求/token/成本和每角色请求次数；工具调用额度在整单共享，不能通过新运行重置。短事务按订单→能力→意图的顺序加锁，与终止路径一致。
- 本轮费用测试覆盖真实平台预算与合成推理回执；固定字体/OFL文件与已售绑定已在后续接入；其他生产资源和基础设施成本计量仍需G0及完整成本台账接入。当前禁售和完整生产阶段启动门禁继续生效。
- 图片检查实际 PNG、尺寸、单页、元数据和完整解码；视频检查实际 H.264/yuv420p、1080×1920、30fps、合同帧数±1、原图路线无口播音轨，并用 FFmpeg 完整解码。
- 此处的机器检查不是商品视觉真值、事实质量、素材许可或观看体验验收。原图无声QC与封存已由后续接入补齐，仍须完成两个独立新进程语义复核及发布门禁。
- 临时媒体只在本项目 runtime/media-work、runtime/media-inspect 下；完成或失败后清理本次目录。未使用 Docker、WSL、虚拟机或浏览器。
