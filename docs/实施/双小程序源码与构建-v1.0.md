## 源码分层

- `src/mini-alipay/`：支付宝入口、宿主适配、17个页面入口、Taro配置。
- `src/mini-douyin/`：抖音入口、宿主适配、相同17个页面入口、独立构建配置。
- `src/shared/ui/`：17个共享页面与C主题，按页面条件显示三栏根导航；详情无底栏。
- `src/shared/client/`：生成式API客户端、内存会话、账户分隔恢复ID、同照片批次重试与逐文件保存日志。
- `src/shared/platform/`：宿主接口、Taro通用网络/照片、原生订单创建恢复；`my/tt`保留在各端适配入口。
- `src/shared/contracts/endpoints.generated.ts`：从现有接口目录生成，调用方不再手写另一份路径表；由`./scripts/run.ps1 contracts`更新。

两端各构建17个页面入口，共享业务和UI；不是把一个安装包同时上传两个平台。网页Plus与管理前端尚未实现，也不由本小程序构建替代。

## 会话、原单与恢复

普通目录浏览不登录；上传、本人资源和交易通过本宿主临时code交换平台会话。Bearer只存在内存，所有者由后端判断。恢复ID按宿主与买家分隔，换号不复用原账户草稿；异步私有响应在账户变化后被拒绝。照片路径、买家文件与领取短链不写入路由或分享参数，短链仅保留于当前页面内存。

付费和写操作使用原逻辑动作的幂等键，不自动重试网络不明确的写请求。照片批次在复用同batch_id时复用草稿、资产和绑定；API在尚未上传时明确返回UPLOAD_NOT_COMPLETE，使重试先确认旧资产再决定是否上传，不能覆盖已经成功的素材。进程重启后的选片/批次UI恢复尚未完整接线。

原生支付回调只返回“已返回/取消/未知”，履约仅依据后端CONFIRMED。抖音requestOrder调用前写本安装的原单创建日志；返回原生orderId后才能拉起原单收银台。创建回调丢失或在创建中退出，后续不再次requestOrder，转原单核验；已返回的原生orderId可继续使用。通道版本未显式固定时关闭调用。

页面前台轮询从2秒退避至10秒并加抖动；429遵守服务端Retry-After。隐藏/卸载后停计时器并忽略旧响应，不把退出页面作为停止云端制作。完整真机网络恢复/账户切换仍需验证。

## 相册日志

保存队列按买家、安装、订单、manifest版本记录，每个媒体文件分别经历PENDING→DOWNLOADING→SAVING→SAVED/FAILED/UNKNOWN。成功项跳过，失败项新attempt；写相册回调中断后保留UNKNOWN，只有用户核对“确认未保存”才再保存该项。文案独立复制。

本安装已收到的SAVED不会因服务器回执网络失败被降为FAILED；回执使用持久化时间和原请求体重送，避免同幂等键携带不同内容。旧账户的进行中队列在换号后不得继续执行。离开页面停止领取下一项，已在进行的原生调用按回调或后续UNKNOWN处理。

支付宝当前只实现可明确调用的图片保存；视频直存未核验，调用时返回明确错误，不能把下载或图片成功当整包已存。抖音图片/视频方法已有适配源码，但仍须真机核验权限与回调。

## 上传协议

支付宝发放POST授权，Taro `uploadFile`提交一个名为file的multipart文件；抖音当前发放PUT原字节授权。后端保留原PUT入口兼容旧授权，新增POST入口，均使用短期上传能力票据，不携带业务Bearer到文件地址。

POST在读取文件前核验票据；文件最多10,000,000字节、完整multipart最多10,032,768字节，只接收一个文件、零普通字段。使用官方`@fastify/multipart`解析，原始SHA、真实解码、像素、EXIF处理仍由服务端实施，客户端文件名不决定对象路径。上传入口沿用原有UploadGrant允许的POST/PUT合同，无公开schema变化。

## 构建与产物

依赖由package.json/pnpm-lock.yaml锁定，Webpack/Babel/PostCSS显式补齐Taro构建peer。Taro小程序采用Webpack构建；Vite保留给将来的Web，不使用Taro的Vite编译链。

```powershell
# 两个值均为可公开的宿主配置，不能放模型/支付/运营密钥
$env:TARO_APP_API_BASE = 'https://填写已备案并获准的小程序服务域名'
$env:TARO_APP_DOUYIN_TRADE_CONTRACT = '' # 仅在真实协议准入后固定对应版本
./scripts/run.ps1 build:alipay
./scripts/run.ps1 build:douyin
```

未设置服务域名时仍可编译，但运行时明确提示服务未配置，不回退到模拟数据。产物分别在`runtime/build/mini-alipay/`与`runtime/build/mini-douyin/`，开发工具中还需配置实际appId、服务/上传/下载域名、隐私声明与获准能力；这些设置没有在本次执行中伪造。

构建子进程的工作目录为`runtime/taro-work/<宿主>/`，SWC缓存、构建与临时资料留在runtime，不运行Docker/WSL/虚拟机。首页3张示例来自用户保留C稿的局部派生，只标示例商品照片；产物`example-source.json`记录坐标，不修改原图，也不称为某方案真实样例或买家结果。
