# 社区许可与发布申请接入

2026-10-28｜需求 v3.1 / 开发契约 v1.1 / C 设计 v1.0｜局部实现，社区完整流程仍未验收。

本专项补齐作者提交发布所需的商品、授权、样例和许可选择，以及服务端的冻结、复查和退役停售。它承接[社区界面与作者工作台](社区界面与作者工作台接入-v1.0.md)，不改变58项需求或核心小程序优先级。本专项当时使用显式READY数据，不能把申请表单算作自动样例生产；后续原图无声样例的实际生产与复核见[独立样例接入](社区样例独立制作与复核接入-v1.0.md)。

## 作者交互

作者在已保存的草稿中选择自己的商品和已识别档案，选择关联当前照片版本的“商品使用权”“样例公开授权”，再针对每种制作规格申请私有样例。未保存修改或版本冲突阻止提交，旧草稿样例不能为新版本背书。商品选择、授权记录、样例和许可列表使用本人查询或公开目录及服务端游标。

许可展示固定版本全文、名称、派生条件与内容摘要，作者必须明确确认。发布请求携带许可ID、摘要和确认值，不把页面打开视为同意。只有当前草稿每种规格都有READY样例且资料齐全，界面才允许提交；服务端仍逐项重新检查。提交成功进入审核，作者可查看审核理由、修改后提交新版本。

前端在`src/shared/ui/creator-workflow.tsx`，由草稿页引用；授权及审核状态在`community.tsx`。没有新增第18个页面或另一套视觉方案，继续沿用C主题。页面目前只有类型检查和双端编译证据，未做宿主真机交互验收。

## 许可版本与权限

新增迁移`017_community_licenses.sql`及`src/api/modules/licenses.ts`。许可状态为DRAFT→ACTIVE→RETIRED，DRAFT也可直接退役。全文、版本、摘要与派生条件禁止原地改写，禁止删除或复活退役版本；修订需登记新的ID。摘要由实际全文UTF-8字节计算，读取时校验结构和摘要。

| 接口 | 身份 / 作用 |
| --- | --- |
| GET /preset-licenses | 限流公开摘要目录，排除退役记录 |
| GET /preset-licenses/{license_id} | 限流公开指定版本全文，保留历史可读性 |
| POST /v1/internal/p01/preset-licenses | moderator:review，登记DRAFT |
| POST /v1/internal/p01/preset-licenses/{license_id}/decision | moderator:publish，按预期状态/摘要启用或退役 |

前两条业务基路径为`/v1/p01`。管理写入继续使用独立凭证、幂等、审计与事务，不接受买家token。公开DTO不返回操作人或审核内部记录。数据库不内置一份假定可商用的许可；运营须登记并审核自己的有效版本。测试全文明确为合成数据。

退役与审核、发布、准入、恢复销售按“先许可、后发布/变体”的锁顺序串行化。退役在同一事务中停止受影响变体的新销售、递增修订，并将申请准入状态挂起；已售执行快照保持独立，不能原地改写。社区派生必须沿用父版本许可，父许可退役或禁止派生时拒绝新派生；第三方资源仍需作者另行提供有效授权，不因复制配置自动取得使用权。

## 商品、样例与发布证据

授权证明只能引用本人、未过期、READY的RIGHTS_EVIDENCE附件，不能把普通商品照片冒充证明。商品授权冻结`product_id + photo_version`；制作样例需要同一照片版本的商品使用权和样例公开授权。第三方资源许可关联明确的`resource_version_ids`。

`compilePresetConfig`将已注册的风格和执行蓝本映射为冻结来源：保留蓝本路线、输出规格与时间轴，采用所选官方风格的创意组件和Skill引用。原图工具读取`platform_style_id`，避免社区ID使风格失效。所有组件及资源登记内容带版本摘要；样例源摘要与当前编译结果不同就拒绝发布。不支持的风格/路线组合显式拒绝，名称和说明不作为可执行指令。

发布提交、审核批准和实际发布均检查样例归属、草稿修订、配置/来源摘要、每种蓝本覆盖、原授权记录与当前许可。样例媒体必须位于本人租户的独立`samples/<sample_id>/`前缀，匹配私有写入登记、实际文件长度与SHA-256，拒绝拿商品输入对象直接充当公共样例。发布保存许可接受主体、时间、全文摘要及编译配置。

内容/权利审核通过仅将权利资料核验为VERIFIED；发布前再次检查。发布创建不可变社区版本，销售保持false，必须另做能力、成本、资源及完整质量准入。修改同一草稿版本的已提交请求返回冲突；相同内容重试恢复原申请，不能重复创建另一份发布。

## 当前生产边界

SAMPLE申请要求生成/Codex开关启用，且新鲜Worker心跳声明全部七个样例处理器；独立额度、运行/视觉准入和授权也须有效。后续已接入原图无声实际媒体/后期/QC、独立双复核和独立成本域；其余生成式/有声/资源、生产准入及公开样例生命周期仍待完成。不可用时503，不建立无人执行的排队记录或启动推理，详见[样例实施](社区样例独立制作与复核接入-v1.0.md)。

当前许可与发布专项使用显式READY/QC元数据夹具配合实际登记的PNG文件；这可以证明权限、字节校验与状态事务，不能证明样例由模型制作、整包质量合格或真实授权合法。社区执行Bundle签名/资源字节消费/成本准入、真实Codex隔离、完整生成式路线、设备与云部署仍未完成，默认付费和发布开关保持关闭。
