# 商品档案推荐与可用方案选择 v1.0

2026-10-30。本轮落实 P01-F21 的“识别后推荐、自由选型”主流程，延续双小程序优先及方案 C。推荐是只读选型辅助；不自动选方案、不创建计划、不报价扣款，不替代生成、原生音频、付款与交付门禁。

## 需求与交互

用户拍摄 3–5 张同一件商品的照片，视觉分析完成后，在商品档案页看到“适合这件商品的方案”。每张推荐卡展示方案名、官方或社区来源、作者、风格标签、理由及适配规格数量。点击后带上原方案版本及推荐规格进入已有详情页，用户仍需主动选择、确认素材清单后继续制作。

原先选择的方案及规格始终保留。用户可以打开原方案，也可以进入完整方案社区自由选择。完整目录保留尚未开放的设计规格并明确标识准备状态；商品推荐列表仅返回已开放、当前输入足够且通过本轮预筛的规格。推荐不保证之后的报价一定可用，详情、计划与报价仍以当时的状态和精确版本重新核验。

没有推荐时给出浏览方案、补拍整体或清晰细节的路径。商品身份冲突或缺少整体照片时提示重拍，不增加必填商品表单，不要求用户理解模型参数。

## 判别依据

先检查当前账户、商品存续期、照片版本、档案版本与商品锁。照片集合必须来自本账户同一商品的 3–5 个有效 READY 资产，照片项、摘要、去重、集合哈希与档案照片版本一致。被删除、过期、替换的照片不能继续用于推荐。

类别来自已经生成的商品档案，用于展示风格路由，不升级为商品事实或认证。固定规则将手作、饰品、食品、家居、日用等类别匹配到官方风格；无法匹配时优先提供极简、竖版和章节等通用方向。

可见配色或结构特征只有在 `OBSERVED` 状态下，而且其证据及来源照片都属于当前照片集合时，才能提升色块或信息卡片方向的排序。假设、未知属性、标签文字及缺失证据的观察不参与特征加分，也不会出现在推荐理由中。

社区方案按平台编译后冻结的 `platform_style_id` 获取风格路由。作者输入的名称、标签、描述不能自定推荐分数或引入可执行 Skill。

## 技术与约束

沿用登录接口 `GET /products/{product_id}/preset-recommendations` 和原有 `RecommendationList` 契约，不增加数据库迁移。支持每页 1–100 条，客户端每次 4 条。排序为分数降序、方案 ID 升序；签名游标绑定策略版本、账户、商品、档案及照片集合。每次最多扫描 500 个候选并返回继续游标，没有原来只读取前 100 套方案后截断的问题。未准备好的候选可以产生空页及继续游标，客户端保留“加载更多”。

预筛检查执行规格关系表与展示数据中的开放状态、准入和价格一致；照片是否包含整体、生成路线是否还具备细节或标签、生成服务开关；引用模型全部处于准入状态；可信 Skill 包已准入并与本地冻结包对应；字体和其他资源许可未过期、未撤销且摘要匹配。运行服务关闭、Codex 准入配置不可用时返回空列表。模型、规格或许可撤下后，后续请求立即重新筛选。

推荐请求不调用模型，不分配生成实例、不写计划、报价或订单。个性化响应使用 `private, no-store`。客户端在读取前后复核当前账户、草稿及档案版本，丢弃过时响应。该入口与支付宝、抖音小程序共享同一界面和业务客户端。

推荐预筛不运行完整订单冻结流程，也不代表真实生成、原生音频、质量、可售或生产准入已经通过。完整模型参数、预算、原生音频、风格绑定、计划和独立审查仍由既有计划、报价及制作门禁负责；任何失败都不得以推荐结果作为绕过依据。

## 本轮验证边界

只做推荐策略、客户端隔离、原生 PostgreSQL 关键集成、共享小程序界面回放及交付所需构建/启动检查。模型、准入元数据和浏览器演示商品使用明确标记的合成夹具；不调用真实收费服务。截图和录制来自实际运行的共享页面，不是小程序真机证据。

结果、尝试记录与素材索引见 [准确源码证据](../verification/recommendations-source.json)。完整测试套件、小程序构建及真机、真实生成/音频、真实支付、云部署和长稳运行保留为未完成项，不要求本轮全面测试绿灯。

## 小程序延后挂载与首次加载

视觉档案异步完成后，推荐组件才被挂载，此时原生页面首次显示事件已经结束。推荐组件通过自身挂载 effect 触发首次查询，后续仍由原分页 hook 处理更多页、页面隐藏时取消和重新显示时刷新；不变更全局分页 hook，不自动创建计划或收费。

新增 `scripts/check-recommendations-mount.ts`，使用实际 React、共享组件和原分页 hook，模拟页面已显示后才挂载组件。首次自动加载、继续翻页和返回后刷新三项专项通过；并非小程序真机通过。原后端、客户端、策略、已有测试和合同/资源与上次验证字节一致，原截图录屏按原版本留存。当前源码及构建见 [首次加载证据](../verification/mini-mount-source.json)。
