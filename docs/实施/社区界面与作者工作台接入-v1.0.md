# 社区界面与作者工作台接入

2026-10-28｜需求 v3.1 / 开发契约 v1.1 / C 设计 v1.0｜新增6个共享页面与5个恢复查询；应用仍为 IN_PROGRESS。

本专项优先落实小程序社区。双端从11个共享页面增加到17个，继续使用已定型的果橙、奶白、深绿墨与照片印样。既有23设计单元、22组件和原始设计归档不变。网页 Plus 与管理网页入口仍待开发，本专项没有将P1网页当作P0小程序替代。

## 可操作入口

| 路径 | 当前行为 |
| --- | --- |
| `pages/favorites/index` | 查询本人收藏、服务端游标翻页、打开方案和取消收藏 |
| `pages/creator/index` | 查询本人草稿/发布记录，进入创建、续编、授权与治理 |
| `pages/draft/index` | 创建受控方案、选择主风格/规格/资源、expected_revision保存；冲突时保留当前输入；恢复原草稿样例与发布记录 |
| `pages/rights/index` | 选择授权用途、填写说明、私有上传证明图片、幂等提交和查询本人审核状态 |
| `pages/publication/index` | 从服务端恢复本次发布状态、商业准入及草稿/已发布版本入口；审核通过不冒充可售 |
| `pages/moderation/index` | 举报具体方案版本，查看本人举报/涉及本人方案的治理元数据，形成决定后申诉并恢复本人申诉状态 |

方案详情增加收藏、保留来源派生、举报、已授权公开样例查看。私有样例与公开样例分别标识；样例画面不冒充买家自己的结果。目录、订单和收藏使用实际服务端游标，去除“只显示100条”的临时限制。返回/离页停止接收旧列表结果，筛选更新不会混入上一次请求的条目。

共用组件/页面生命周期在 `src/shared/ui/base.tsx`，社区页面在 `src/shared/ui/community.tsx`；既有业务页面仍在 `pages.tsx`。两个宿主分别登记17个页面并独立构建。照片、授权附件与短链接不放进路由参数；当前会话、归属和资源权限由服务端校验。

## 恢复查询与契约

| 新接口 | 访问边界 |
| --- | --- |
| `GET /rights-records` | 本人授权记录的公开DTO；不回传证明正文或私有附件定位 |
| `GET /preset-drafts/{draft_id}/samples` | 先检查草稿归属；游标绑定当前用户与草稿 |
| `GET /preset-publications` | 本人发布记录；不泄露其他作者配置 |
| `GET /appeals` | 本人提交的申诉 |
| `GET /creator/reports` | 仅涉及本人所著方案的治理DTO；不返回举报者、证明或私有陈述 |

收藏现在遵守limit与游标，游标绑定账户；当前可售状态按实际变体计算。方案停止公开后仍允许本人取消收藏，不以公开状态阻止清理自己的关系。

## 编辑与私有证明

作者只能选择已注册组件/制作规格/资源。服务端拒绝未知字段、可执行描述、重复规格、重复资源、多个主风格，以及与任一所选制作路线不兼容的组件。不能用显示名称指定模型、价格或工具地址。

派生必须从fork入口保留父版本及许可关系，不能在普通创建时自报来源，或在后续修改时移除/替换来源。保存带expected_revision；同版本并发修改只有一份成功，旧编辑收到409，原幂等键可恢复已提交的同一结果。

`src/shared/client/evidence.ts` 在申请上传后先查询原资产完成状态。只有明确尚无字节时才上传；网络结果未知、权限或摘要失败不会直接覆盖对象。补试保留原批次/资产/完成键；账户切换立即终止本批次，不能将前一账户的附件绑定给新账户。证明经现有真实解码/归一化流程后仍为私有资产。授权提交成功后页面释放所选照片字节。

## 本轮验证

`tests/integration/community.test.ts` 共9项，使用实际Fastify、原生PostgreSQL、Sharp、本地私有文件和客户端调用：

1. 所有恢复查询要求登录，其他作者不能读取草稿或嵌套样例。
2. 未知组件/字段、可执行描述、重复项、多主风格和不兼容路线被拒。
3. 修改幂等、乐观冲突、并发修改与派生来源保留。
4. 收藏翻页无重复，跨账户游标拒绝，实时可售投影及停止公开后取消收藏。
5. 样例/发布记录由原库恢复，不返回private字段；排队记录不被伪造成已生成。
6. 两作者/两买家下的治理元数据隔离、决定前申诉拒绝、本人申诉私有恢复。
7. 实际证明上传完成回执丢失后重试，不重复上传或提交授权。
8. 上传中切换账户，不把旧媒体关联到新账户。
9. 含冒号/点的8与128字符原操作键可以重放同一草稿；过短/129字符/不允许字符在写入前拒绝。客户端单元测试另外使用Ajv核对业务与管理公开头部的相同边界，并确认非法键不发网络请求。

样例与发布恢复测试包含显式数据库夹具，不能证明样例生产或发布审核全链路已运行。双端构建仅证明源码可以编译，不证明原生布局、选择器、播放、宿主身份/支付/相册或真机交互通过。最新全量命令、报告、源码和运行契约摘要见[实现索引](../../assets/implementation/current.json)。
