# 自愿使用反馈与分群运营统计 v1.0

2026-10-30 · 一品成片 · 需求 P01-F17 / P01-F23 / P01-F50 · 方案 C 保持。

本轮补齐领取后的自愿反馈，以及运营后台能从持久记录可靠读取的统计。F17 仍为部分实现；推荐曝光、识别准确率、无人工自助成功率和完整成本不凭空给分。按用户要求只做针对性验证，不等待全套测试绿灯。

## 1. 客户如何使用

支付宝和抖音小程序共用领取页。在整套素材下方，可选“准备使用 / 已经用上 / 还需调整”，随时更改或撤回。不要求填写表单、上传发布链接或证明，不影响相册保存、复制文案和原有售后入口。

读取或提交失败时保留原素材领取功能，反馈区域提示重新读取。未知回执后先读取当前值，旧修订号不能覆盖更晚的选择或撤回。反馈只描述客户自报体验，不自动代表真实发布或投放。

## 2. 接口、权限和并发

| 方法与路径 | 作用 | 约束 |
| --- | --- | --- |
| GET /v1/p01/orders/{order_id}/usage-feedback | 读取本人反馈 | 原产品会话、租户/所有者、已付且首版完整交付 |
| PUT 同一路径 | 选择或撤回 | choice + expected_revision；空选择为撤回，不缓存个人正文 |
| GET /v1/internal/p01/metrics/product-insights | 读取运营分群明细 | 独立 metrics:read；UTC 半开窗口，不超过90天 |
| GET /v1/internal/p01/metrics/accounts/{tenant_id}/{user_id} | 读取账户分组 | 独立 metrics:classify |
| PUT 同一路径 | 标记分组 | 独立 metrics:classify、管理幂等键及审计 |

反馈初始返回 revision=0、choice=null、updated_at=null。更改时修订号递增；相同当前选择重复提交不产生新记录。不同选择使用过期修订号返回409。订单所有者锁与删除操作共用，同一事务读取/比较/更新。撤回保留空选择修订号，阻止迟到旧写入恢复内容。

新增033迁移维护 order_usage_feedback 与 metrics_traffic_classifications；1—32迁移原字节保持。反馈不写冻结交付清单。订单媒体撤回、商品删除触发反馈物理清除，并拒绝重新写回。没有通用幂等结果副本残留个人选择。

## 3. 运营如何使用

启动当前 API 构建后打开 `/ops/metrics`，用 metrics:read 独立令牌连接，选定时间窗和流量分组。原履约总览仍是全部流量；新增明细按 ALL / EXTERNAL / INTERNAL_TEST / UNCLASSIFIED 读取。切换、断开及过期响应沿用原清理规则，令牌仅在内存中保存。

账户分组只能由 metrics:classify 的运营令牌经管理API维护，普通客户和仅查看统计的人员均不可自行标记。PUT正文示例：`{"traffic_group":"INTERNAL_TEST"}`；带8—128字符 `Idempotency-Key`，先标记测试账号，再查询 EXTERNAL。未标记不默认为外部。EXTERNAL 表示运营标记，不保证真人、真实收费或赛事有效用户；测试环境记录始终是测试证据。

## 4. 每项统计的来源和边界

| 统计 | 原始来源与去重 | 时间口径 / 未知处理 |
| --- | --- | --- |
| 视觉任务与尝试 | analysis_jobs、analysis_attempts | 任务创建入窗，包含免费尝试和原任务重试 |
| 机器字段覆盖 | 原识别任务绑定的初始 profile_versions | 分开观察、OCR、推测、未知、冲突；用户纠错不计机器事实 |
| 字段证据占比 | (观察+OCR)/(观察+OCR+推测+未知+冲突条目) | 这是结构覆盖代理；全未知为0，无字段为null，准确率始终null |
| 方案选择 | 同账户、商品、预设版本的 plan_versions 去重 | 计划创建入窗；不冒充推荐曝光或点击 |
| 付款 / 首版交付 | orders、首版 delivery_manifests | 订单创建入窗、当前确认状态；后续版本不重复 |
| 相册保存 | SAVED回执按账户、订单、文件去重 | 首次已知服务器确认入窗；旧记录缺服务器时间单列，不用客户端时间回填 |
| 自愿反馈 | 当前每订单唯一反馈 | 最后更新入窗；只保留当前选择，撤回从已用数移除 |
| 社区公开版本 | 公开、PUBLISHED及样例已公开的版本 | 发布申请创建入窗，读取当前发布状态；不等于能力已商业准入 |
| 社区有效复用 | 已付、首版交付、非作者，同账户/商品/预设版本去重 | 订单创建入窗；收藏、作者自用与重复订单不累加 |
| 制作已结算费 | 订单 spent_micro | 订单创建窗口，包含失败尝试的实际结算，不含未结算预留 |
| 平台免费费 | platform_budget_reservations 实际结算 | 预留创建窗口；识别/免费尝试/样例等已入账调用，待查与无法分组单列 |
| 人工成本 / 完整总成本 | 尚无完整账本 | 均为null；两类不同窗口费用不直接相加冒充期间成本 |

旧保存回执新增 received_at 默认为历史null，新回执采用服务器时间；状态变化由数据库维护时间，重复状态不刷新。平台账户新增 owner_id，并只对能关联既有用户的历史 scope_id 做可靠回填。
