# 社区公开样例：独立持有、撤回与到期

2026-10-28｜需求 v3.1 / 开发契约 v1.1 / C 设计 v1.0｜本专项已有源码与本地测试，完整产品及生产准入仍为 IN_PROGRESS。

## 1. 采用行为

原 `public_samples` 表承载作者的私有 SAMPLE 制作。此前发布直接改变其可见性，媒体仍受私有商品的短期保留限制；现已移除该路径。私有制作结果始终保持 PRIVATE，审核通过后生成 `authorized_samples` 独立记录和独立对象，发布引用新的公开样例 ID。

作者分别确认方案许可及公开样例授权。公开副本从审核批准起最多保留30天，截止不可延长；改变条款、样例或草稿版本后前端重新要求确认。普通买家的拍照制作流程没有新增确认步骤。

公开只包含经过审核的样例成品图片/视频，不包含原商品照片、档案、推理上下文或买家数据。保留最小授权主体、来源ID、照片版本和摘要用于审计，不因公开展示延长私有输入的有效期。

## 2. 审核、准备与发布

1. 提交与批准仍检查当前私有样例的完整制作/复核证据、实际文件、逐蓝本覆盖、照片版本权利、许可全文摘要及组件/资源绑定。
2. 批准事务冻结公开授权输入，写入 PREPARING 副本及 PUBLICATION / PUBLIC_SAMPLE_PREPARE 持久任务。事务提交后才允许对象写入；审核回复不冒充复制完成。
3. 独立 Worker 精确复制已审核成品，不重新生成或购买推理。目标为 `tenant/authorized-samples/id/`；写入前登记，原图商品/订单/运行归属均为空，单独绑定公开样例ID和30天截止。
4. 副本全清单、真实长度与SHA核对通过后，事务置 READY。发布再次核对许可、父许可、当前编译映射/资源、独立副本与实际文件，再原子公开方案和副本。发布与商业准入继续分开，默认禁售。
5. 已准备副本的发布不再读取已到期的私有照片或档案；原输入自然到期并完成受控删除后，仍可使用已经批准且有效的独立副本。

恢复时只观察原对象与摘要。WRITING/UNKNOWN 等原回执核对，不再次 PUT；旧租约不能提交，撤回时递增代次并取消准备阶段。迟到 PUT 仍登记为需删除，由独立媒体维护器回收。

## 3. API 与作者界面

- `PublicationRequest` 新增必需的 `accept_sample_publication=true`、`public_sample_retention_days=30`。
- `Publication` 返回公开副本状态、ID和截止；状态为 NONE / PREPARING / READY / PUBLISHED / WITHDRAWN / EXPIRED / FAILED。
- `GET /v1/p01/public-samples/{sample_id}` 只接受独立公开 ID，返回带“授权样例，不代表你的成品”标签的短期媒体链接。私有 SAMPLE ID 不能走该入口。
- `POST /v1/p01/preset-publications/{publication_id}/sample-withdrawals` 仅本人可调用，校验修订与幂等键；返回更新后的发布记录。
- 双端共享发布页显示准备状态与到期时间，并提供说明影响及确认撤回的入口；尚未做真机验收。

签名下载使用独立 PUBLIC_SAMPLE purpose，读取前后都核对当前授权。实际文件必须匹配完整登记清单和摘要，返回 no-store；已签发链接不能绕过撤回、许可/资源撤销或到期。私有样例仍使用本人入口。

## 4. 撤回与隐私边界

撤回先结束所有受影响的公开副本、隐藏方案并停止新制作，再标记对象待删；原已售订单快照和交易凭据独立。许可退役、资源或权利撤销立即阻断读取，维护器随后结束分发和清理。到期、撤回或失败的副本不能复活，应由新版本重新申请。

私有删除区分两个来源：

- RETENTION：私有素材自然到期，取消并撤权原 SAMPLE，清理原照片、私有样例和受控上下文；保留另行批准的公开副本。
- USER：作者主动删除商品或账户媒体，同时撤回相关公开授权并清理副本。账户删除只处理冻结集合及原截止前的对象，保持其他主体隔离。

签名删除日志在写入前冻结来源和公开副本ID；恢复重放保留该差异。旧版缺少来源的签名日志按 USER 保守处理，不改写旧签名。原日志与检查点不匹配仍阻断恢复，不以空日志绕过。

迁移018补充私有 SAMPLE 的稳定商品列及不可变约束，将 SAMPLE 阶段、角色实例和源样例纳入原隐私关系视图，受控脱敏表范围增至33表。无法证明独立授权的旧公开标记降为私有，相关发布挂起，不把历史可见性当成新授权。

对象回收、主库脱敏与日志重放不代表底层页/WAL、生产备份、外部供应商副本或财务恢复已完成。隐私总状态仍保留 PARTIAL_BLOCKED；已下载到外部设备的文件也不承诺全网撤除。
