# 参考帧独立身份核验 v1.0

2026-10-28｜需求v3.1 / 开发契约v1.1｜独立服务核心已有，完整生成产线仍未完成。

## 目的与边界

生成视频前，需要核对生成参考帧是否仍为用户照片中的同一商品。商品类别接近不等于包装、颜色、轮廓、可辨文字和细节一致；模型不能自行补充无证据卖点。该服务输出参考帧身份报告，不授权最终交付，也不能代替正式整包事实/风格双复核。

当前源码位于`src/worker/generation/reference-{material,report,service}.ts`、`context.ts`和`src/worker/tool-gateway/reference-tools.ts`。调用者必须持有原订单PRODUCTION阶段的有效租约，原冻结变体/商品档案/照片集/SkillBundle/模型合同/实际生成提交必须一致。PER_SHOT_AI按镜头收齐参考帧；REFERENCE_FILM声明整片参考帧，但现有生成网关尚未接通该槽位及后续视频购买。

## 输入与执行

1. 从不可变照片版本重建3–5张原图，核对实际PNG字节、摘要与照片集引用；恢复商品identityLock、证据锚点和unknown项。
2. 收集所需生成提交，验证实际私有对象、尺寸、模型合同和视觉准入限制；缺失、篡改或非当前版本直接阻断。
3. 冻结包含全部原图、生成帧、每个锚点、风格及范围的审查包及hash。
4. 创建独立REVIEW_FACTS实例，仅授权`extract_review_evidence`与`persist_stage_result`，实际图片通过已有受控Responses出口提交。该例外不放宽其他PRODUCTION角色工具权限。
5. 报告必须覆盖每张生成帧、每个锚点和真实原图证据；PASS/FAIL/UNCERTAIN保持独立。缺项、伪造来源、相互矛盾的PASS或错误thread/hash拒绝。
6. 绑定实际运行、Skill预载、图片推理与工具证据；审查角色释放完成后才可返回通过。未释放、未决费用、失败/未知检查点继续阻断。

## 恢复与并发

原阶段行锁保护首次创建。新Worker接管后复用已完成且包hash相同的检查点，不重新购买推理；未决/失败角色不能通过新实例绕过。租约代次、原截止时间和阶段关联照常生效。没有增加数据库表，私有载荷沿用agent_runs及既有删除规则。

## 验证与未完成项

`tests/integration/reference-identity.test.ts`共15项：真实原图/生成帧、逐锚点报告、接管复用、FAIL/UNCERTAIN、缺帧/缺锚/缺证据、伪造PASS、错误thread/图片、实际字节变化、释放失败、并发创建和截止/阶段拒绝。实际使用原生PostgreSQL、Sharp文件、Node stdio与HTTPS/MCP；模型结论、用量和隔离身份是合成夹具。

待完成：视频购买前强制调用与证据绑定、生成式生产MCP、REFERENCE_FILM参考生成槽位、两条生成式后期/QC/双复核/交付、真实模型G0和原生声音。因此实现证据中`reference_identity_service_implemented=true`与`generated_reference_semantic_gate_implemented=false`必须同时保留。

English: this is a reference-identity review service with actual PNG inputs and per-anchor validation, tested against synthetic model/isolation responses. It is not yet connected to video purchasing or the complete generated production pipelines and does not certify real model quality or final delivery.
