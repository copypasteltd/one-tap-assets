# 原图候选修复与重新验收 v1.0

2026-10-30。需求 v3.1、58 项功能和 C「柚子创作社」设计不变。本专项接通 PHOTO_LAYOUT 的内部自动修复执行链；生成式、原生口播和真实商业运行仍分别待验，不因此取得售卖准入。

## 1. 用户看到的行为

用户仍然只拍照和选方案。首轮素材由事实、风格两名独立角色复核；发现明确问题时，平台在原订单内优化一次。小程序显示「根据检查结果优化素材」，随后继续显示制作、后期、文件检查、双复核和领取状态。没有额外的用户填表、确认购买或隐含补款。

修复不能完成、证据不足、额度不足、权限撤销或修复再次失败时，原订单停止并沿原有退款意图处理；不得交付旧候选凑数。

## 2. 完整链路

```text
首轮 PRODUCTION → POST → QC → REVIEW_FACTS → REVIEW_STYLE
  ├─ 同包双 PASS：DELIVER
  ├─ 证据不足/不能定位/不满足原预算：停止并处理原退款意图
  └─ 可定位的原图失败：同事务撤销旧 DELIVER，核发唯一修复权限
       REPAIR_PLAN（CONTENT + 原风格 Skill）
       → 新 PRODUCTION → 新 POST → 新 QC
       → 全新 REVIEW_FACTS → 全新 REVIEW_STYLE → DELIVER
```

第一名复核给出 FAIL 后，第二名仍可检查同一个已封存包；这个例外仅用于完成独立意见，旧包始终 BLOCK。第二名报告提交、旧交付阶段撤销和新阶段创建在同一数据库事务完成，避免旧候选被并发领取。

## 3. 问题定位与内容约束

问题必须引用原封存包的实际产物、图片/视频帧证据。原图、合同或共享文案上的问题明确影响整包；缺少有效定位时停止，不能把空证据解释成任意修改权限。每次读取修复上下文都重核原包、报告摘要和目标素材清单。

CONTENT 收到原商品档案、原计划、失败报告和允许修改的素材编号，预加载原 Skill，仅可调用计划验证和持久化工具。报告中的文字是数据，不是平台命令。模型不能调用支付、购买、发布或配置工具。

原商品身份、规格、素材清单、风格变体、人物/声音、原台词和时间轴不变。局部图片仅能修改其原图引用、标题及已有证据；全局标题、文案、场景和共享事实依据须整包都受影响才能改。所有文案仍经过原事实约束、固定字体和购买前同源排版规则。

## 4. 新候选与冻结订单

原订单合同、执行快照及其 `plan_hash` 保持原字节。修复计划存入新 `REPAIR_PLAN` 阶段，并绑定成功 CONTENT 运行的输出摘要；后续六阶段只能读取该已完成计划。

实际 PNG/MP4/文案重新生成，各自产物保存 `repair_plan_hash`。原媒体检查点不能覆盖；新阶段的制作/后期查询仅接受 attempt 2，不能退回首轮文件。QC 要求至少一份定位的问题素材具有不同的实际文件 SHA-256，防止只换素材 ID、报告或计划描述。

新 QC 封存修复权限、来源失败包、计划摘要、目标素材及实际文件。最终两份报告必须绑定这个新包和全部实际画面；重新核验运行、Skill 加载、推理回执及工具读取证据。新复核不能复用原制作、原复核、修复规划或彼此的会话/进程身份。旧 PASS 不能批准新候选。

## 5. 费用、时限与恢复

- 首轮保留冻结修复额度 R 和售后额度 A，使用 T−R−A；修复累计不超过 R，总计不超过 T−A。
- 唯一授权绑定原订单、原快照、原截止、失败包、准备阶段和六个新候选阶段；`render_jobs.repair_rounds` 仅从 0 变为 1。
- CONTENT 准备和制作/后期/双复核推理全部进入 REPAIR 费用域；不提高原推理总次数、每角色次数、输入输出 tokens 或工具上限。
- 本专项没有 IMAGE/VIDEO 重购权限。原付费调用或预留处于 UNKNOWN/在途时不得开新修复费用域。
- 实例丢失 ACK 时读取本阶段原角色及检查点；未决角色继续核对，不重买一轮。每阶段使用原租约、代次和截止，交付沿原事务发布和实例释放流程。

## 6. 当前边界

PHOTO_LAYOUT 已接通上述代码及定向集成用例。生成式修复尚需受影响节点选择性重制、未变节点的原付费来源复用以及全新参考核验；原生口播还需要与新音轨绑定的独立听音和明确售出的额外 ASR 额度。历史声音合同只允许一次 ASR，不能静默补额。两类失败当前以 `REPAIR_ROUTE_NOT_ADMITTED` 停止并处理退款，不伪装为已经修复。

外部收费/模型/发布开关保持默认关闭。合成 Codex/模型响应仅验证真实本地数据库、HTTPS/MCP、文件、费用状态和事务，不证明真实模型质量、商业授权或真机体验。
