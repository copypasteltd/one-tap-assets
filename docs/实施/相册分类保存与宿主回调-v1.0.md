# 相册分类保存与宿主回调 / Selective album saving and native callbacks

2026-10-30。落实PRD的“保存整套/图片/视频”、部分成功、只重试未完成项及原安装恢复。全部58项/52项P0、三路线、官方10套/至少14变体与C「柚子创作社」保留。本轮仅执行定向检查、当前构建和页面录制，完整测试不作为源码候选打包的前置条件。

## 1. 用户流程 / User flow

| 编号 | 用户操作 | 实际行为 |
| --- | --- | --- |
| 01 | 打开领取页 | 查询本人原订单的当前素材清单，读取本安装、本人、原订单和清单版本的本地保存记录。仅查看页面不会创建保存会话或调用相册。 |
| 02 | 保存素材到相册 | 按清单逐项保存图片和视频，文案通过单独按钮复制。 |
| 03 | 只存图片 / 只存视频 | 仅执行所选类型，共用本版本的一个原保存会话与逐文件记录；不重新规划、生成、下单或付款。 |
| 04 | 部分成功 | 展示明确保存数量、待核对与未完成数量；已确认成功项跳过。已知失败项可单项重试，权限/空间/版本问题给出相应提示。 |
| 05 | 结果UNKNOWN | 整套/分类重试均跳过。用户先查看相册，只有明确确认未保存，才重试这一项；放弃确认不调用相册。 |
| 06 | 离页或暂停 | 停止后续下载与写入，在创建会话、领取链接和SAVING回执等待后重新检查暂停。已经交给宿主的当前一项等待原回调，不能宣称远程取消。 |
| 07 | 返回领取页 | 直接恢复已有进度；中断时SAVING转为UNKNOWN，下载中转回待保存。原页面迟到的明确成功合并为SAVED，避免新页面按旧UNKNOWN重复写入。 |
| 08 | 清单更新、换账户或领取撤销 | 按买家/清单ID和版本重新建立页面边界，旧队列停止；旧账户回调不能写当前页面。每次领取链接由既有服务端重新核验当前权益。 |

## 2. 双端接口 / Native adapters

支付宝采用`my.saveImageToPhotosAlbum({filePath,...})`和`my.saveVideoToPhotosAlbum({filePath,...})`，替换原图片旧接口及视频固定拒绝。抖音使用对应`tt`接口，先下载成宿主临时文件再保存。两端均运行时检查方法存在，缺失时提示升级，不替换为文件下载成功或另一种素材。

支付宝官方文档说明，连续图片调用必须在上一项`complete`之后继续。本实现记录`success`/`fail`，等待`complete`后才结束这一项；`complete`本身不等于成功。相册接口按同一宿主对象串行化，防止不同素材包队列同时写入。60秒没有完整回调返回UNKNOWN；原调用仍占用串行门，直到迟到的`complete`释放，不因此主动重发。只有`success`且完整结束才标SAVED；已知失败使用固定错误，不记录原始宿主报文。

若保存已经明确返回而本地记录写入失败，不将该项改为FAILED；下次从原SAVING恢复UNKNOWN，让用户核对。服务端回执丢失不会把本地已确认成功改为失败；原键重报，服务端成功回执保持单调，不被迟到失败覆盖。

已核对的第一方依据（2026-10-30）：

- [支付宝图片相册接口](https://github.com/AlipayDocs/open-docs/blob/main/mini/api/%E5%9F%BA%E7%A1%80API/%E5%A4%9A%E5%AA%92%E4%BD%93/%E5%9B%BE%E7%89%87/my.saveImageToPhotosAlbum.md)：最低基础库1.15.0、`filePath`及连续调用回调要求；原文blob `91cab44f9397880417add49e772827943b7ffaa3`。
- [支付宝视频相册接口](https://github.com/AlipayDocs/open-docs/blob/main/mini/api/%E5%9F%BA%E7%A1%80API/%E5%A4%9A%E5%AA%92%E4%BD%93/%E8%A7%86%E9%A2%91/my.saveVideoToPhotosAlbum.md)：最低基础库1.10.0；个人/企业小程序均支持，IDE不能代替真机；原文blob `2578f48226bfc58f8d84efac9100f0c6cc689293`。
- [抖音视频相册接口](https://partner.open-douyin.com/docs/resource/zh-CN/mini-app/develop/api/media/video/tt-save-video-to-photos-album)：保存前需要用户授权，网络资源先下载再传本地路径。

上面的支付宝依据来自国内`AlipayDocs/open-docs`，没有用Alipay+ Super App SDK的版本号替代国内基础库要求。
