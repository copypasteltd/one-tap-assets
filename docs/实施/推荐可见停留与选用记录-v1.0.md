# 推荐可见停留与选用记录 v1.0

范围：P01-F17/P01-F21，补齐识别后推荐到查看方案的体验记录。用户仍只需拍照和选方案，没有新增表单、同意弹层或等待步骤。官方十套方案、社区可信组件、冻结设计C及既有制作/支付/交付合同继续适用。

## 用户交互和前端

共享识别页挂载推荐后主动读取适配清单。每张卡片用节点观察器监听视口：至少50%可见并连续停留500ms才上报一次曝光。退出视口、隐藏页面、进入详情及卸载会取消尚未完成的停留，并释放观察器。返回页面可重新观察，服务端去重防止重复计数。点击立即独立上报并导航到该方案的指定版本和规格，不等待回执。

支付宝使用原生 my.createIntersectionObserver(options)，抖音使用Taro页面作用域适配，浏览器回放使用真实IntersectionObserver。不存在该能力、回调没有有效比例、离线、登录过期或签名过期时直接漏记，不以渲染/接口返回/轮询猜测曝光，不阻碍查看或制作。原生适配已通过类型检查，双端真机仍待验证。网页标签隐藏时也停止停留。

实现参考：[Taro节点观察器](https://docs.taro.zone/docs/apis/wxml/createIntersectionObserver)、[抖音节点查询](https://developer.open-douyin.com/docs/resource/zh-CN/mini-app/develop/tutorial/basic-ability/find-node)、[阿里云原生节点查询](https://help.aliyun.com/zh/document_detail/67559.html)。这些接口说明不能代替本项目真机验收。

## 接口、身份与数据

| 接口 | 输入/输出 | 行为 |
| --- | --- | --- |
| GET /v1/p01/products/{product_id}/preset-recommendations | RecommendationList，可选 measurement.token/expires_at | 保持只读；仅已通过原推荐准入的候选签发15分钟签名 |
| POST /v1/p01/products/{product_id}/recommendation-events | measurement_token、kind=IMPRESSION或CLICK | 本人会话；返回accepted=true及duplicate；自然键幂等，无通用缓存 |
| GET /v1/internal/p01/metrics/product-insights | 原UTC窗口和流量组 | 原metrics:read权限；新增计数及recommendation_measurement覆盖说明 |

签名使用独立HMAC用途，绑定租户、所有者、商品、识别档案及哈希、照片版及哈希、方案版、策略和有效期。正文限制4096字符；服务端先校验签名和期限，再核对当前商品/档案/照片及公开方案版本，旧输入即使已记录过也不能绕过检查。错误签名400，跨账户404，版本变化409，过期或已删除410。具体错误以返回code为准。

034迁移新增recommendation_events与metrics_collection_epochs，001—033原字节保留。事件以租户/所有者/商品/档案/方案版本/策略/类型唯一；数据库冲突处理应对并发重发。GET签发新token、翻页刷新和客户端重复请求均不增加同一上下文的记录。服务器首次接收时间作为统计入窗依据，不接收客户端时钟。与删除共用所有者锁；商品删除触发事件物理清除，删除后拒绝写回。此记录不写订单、预算、费用账本或冻结交付清单。

measurement是推荐的可选扩展；旧卡片没有它时正常浏览，不补造数据。内部ProductInsights新增覆盖对象并允许非空计数，旧内部客户端需同步更新；本仓库生成源、API/管理契约、数据目录、类型、服务端及看板已同步。原契约逐字节留档于contracts-fc7def0。

## 运营读数

| 字段/状态 | 解释 |
| --- | --- |
| recommendation_impressions / recommendation_clicks | 独立自然键去重，按服务器接收时间和当前服务端流量分类查询 |
| started_at | 数据库启用此采集协议的时间，不是每个客户端都已更新的证明 |
| UNCOLLECTED | 整个窗口早于采集起点，计数null，显示未采集 |
| PARTIAL | 窗口跨越启用时点，只显示已采集部分并提示缺口 |
| SINCE_START | 窗口在起点之后；0仅表示没有收到符合条件的上报，不能证明无人看见 |
| evidence=CLIENT_REPORTED | 客户端体验证据；签名证明推荐上下文，不能证明真人确实看见或真实付款 |

快速点击可以先于500ms，故点击可以没有曝光。本轮不生成点击率，也不强制点击小于曝光。测试/外部/未分类仍由有metrics:classify权限的运营人员标记，外部标记不等于真实客户资格。历史识别准确率、完整无人工自助成功率、人工审核/支持总成本保持null。社区现有非作者去重记录仍需真实正金额/未退款/反刷量资格完善，不能当作赛事真实付费复用。
