## 原来源与核验

1. 从首次交付manifest的原packet绑定定位QC阶段；若原制作经历一次受限修复，按该原阶段恢复已提交的修复计划/授权上下文，不重新领取过期制作租约或建立新订单。
2. 原交付封存包必须已ALLOW，实际持久事实/风格报告、推理/工具/身份与原快照仍可核对。后续父版本逐一验证完成请求、不可变清单、候选和独立双复核，最终回到首次封存文件。
3. 生成式来源再次核对原参考帧身份报告、模型协议、已结算费用、完整节点、私有登记与实际供应商成品字节；撤权或摘要不符立即阻断，不用新生成内容补位。
4. QC读取全部实际图片/视频/文案；视频完整解码并检查原尺寸/帧率/帧数与无声要求，生成图与视频逐帧检查原冻结AI可见标识。之后建立新的售后封存包、双新复核和原子交付。

售后不购买图片或视频。原售后预算/推理次数/角色次数/Token/工具总量继续跨所有请求累计，UNKNOWN继续查原回执；原48小时窗口、单次300秒与成品到期时间取最早截止。原制作合同、总预算、支付事实和制作绝对截止均不重置。退费、删除、许可与领取限制继续生效。
