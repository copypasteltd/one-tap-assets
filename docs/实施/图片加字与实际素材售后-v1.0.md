# 图片加字与实际素材售后

2026-10-30。本轮快速收口已交付素材的实际图片调整。支付宝/抖音小程序共享领取组件增加“图片加字”：选一张本单图片、输入最多28字的短标题，受理后生成真实新PNG，经全新核验交付新版本。无需商品表格或模型参数。客服可在原接手工单内做同类免费纠错，沿用原订单已支持范围。原图排版、逐镜生成、参考整片三路线均接通；不将本轮范围认定为完整F12或完整产品验收。

58需求/52项P0、三路线、10套官方风格/至少14变体、C设计与17共享页面保持。业务77/管理32操作没有新增；生成契约同步补齐既有管理操作目录，提供IMAGE_TEXT请求及互斥字段和清单能力声明。

## 原授权、费用和恢复

`revision_policy.image_text`是可选售前字段，版本YPCC-IMAGE-TEXT-1，绑定max_chars=28、max_lines=2、panel_fraction=0.22、FONT_BINDING与原风格色值。没有该字段的历史订单不能临时增加授权。新清单的revision_capabilities仅投影原合同，不作为新的售后权利来源。

使用原售后额度、用户一次成功机会及原冻结的角色/Token/工具/推理上限。300秒执行、48小时售后及原领取期取最早绝对截止；更换请求/实例不刷新。UNKNOWN沿用原意图和原回执，不重复买单。不增加图片/视频模型生成、ASR或听音采购；两条原生有声路线保留原视频/音轨/转写/听音和许可，原声音输入继续进入新审核。

`private.image_text_output`持久化新图片的来源、目标槽位、原策略哈希、完整文字行、宽高及实际输出SHA。迁移029禁止改变已登记意图，仅允许既有隐私删除规则清空。重试依原意图确定性重算，不接受客户端任意文件或新的来源ID。迁移1–28原字节保持，主开发库29；专项从27升级到29并重复执行，原UNKNOWN费用未变。

## 核验与交付边界

新增PNG在后期检查、独立QC和最终提交前按原图/冻结策略重算，再核对私有文件实际SHA。已预检后替换文件仍阻断，新清单不发布，旧版仍保留。事实和风格角色输入保留所有原商品/镜头图，并补上当前版本中每张已改图；不能只看旧图或沿用旧PASS。独立推理、工具证明、输入摘要和新报告共同绑定本次修订。
