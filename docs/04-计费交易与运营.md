## 售卖对象与消费体验

每笔订单售卖一个商品、一个方案版本和一个执行变体的完整媒体/文案清单。10套/至少14变体分别定价，不按“调用一次模型”向用户交付。价格含图片、关键帧/人物参考、逐镜或整片视频、声音/字幕/音乐、商品卡/封面、质量检测、修复、存储/下载和许可等成本；全部当前未定价，不默认9.9元。免费范围须明示，选中方案不等于付费授权。

预设卡显示作者/版本、授权样例、效果变体、风格/节奏、AI演绎/声音、交付数量、价格与预计时间。确认页展示完整合同并取得主动付款；内部模型/seed/运镜参数不成为买家必填。用户无需人工沟通或网页编辑，保存不另收下载费，续存不扣修改机会。

报价15分钟有效，冻结档案/商品锁、plan_hash、方案/变体/作者及来源许可、实际模型/能力/费率、人物/声音/资源、原生/交付规格、时限/修复/成本上限、全清单和渠道。历史订单按快照履约，不能因模型替换、供应商涨价、风格/声音变化追改合同。换商品/方案/执行变体或新增产物重新报价。

## 自动履约、相册与退款矩阵

| 情况 | 处理与费用 |
| --- | --- |
| 输入/商品锁不充分、模型/变体未准入、尚未定价 | 收费前阻止；补拍或明确改选，不假称任意3张能做任意生成效果 |
| 合格输入，无任何手填商品信息 | 先多模态识别商品/可见特征，证据支持后自动用于文案；未知材质/尺寸省略，不要求补表，不降低清单 |
| 视觉识别服务失败 | 报价/收费前初始加最多1次重试，仍失败明示稍后重试；不虚称已识别 |
| 档案已有效，文案模型失败 | 基于档案的规则文案自动回退继续制作，不跳过识别或转人工代做 |
| 缺产物、坏视频、商品包装/结构变化或错误台词 | 原合同预算内最多一轮修复；仍失败或超过已冻结硬截止全额退款，不用局部包强制抵扣 |
| 模型下线、额度/声音能力或供应商费率变化 | 暂停受影响新报价；旧单用原合同可履约能力完成或退款，不静默换模型/引擎/声音 |
| 参考帧商品错误 | 在视频提交前检查并按预算修复，不能为错误参考继续购买整片 |
| 原生片有声但后期缺字幕/音乐/商品卡 | 继续已包含后期；不能让用户再次付费补齐配方效果 |
| 人物讲解无音轨、原声被二次配音或字幕不符 | 按质量失败修复；不改交静音片，静音基础展示合同另算 |
| 已付款未开始，用户取消 | 与任务启动竞态锁定，退实付 |
| 执行中主动取消 | 按购买前已明示政策售后；不能虚称一定瞬时停止 |
| 设备拒绝相册权限、空间不足、网络断开 | 作品保留在云端有效期内，只重试下载/保存，不重复计费或渲染 |
| 下载成功但相册保存失败 | 仍显示待保存/失败，不标整套已入相册 |
| 云端结果到期 | 显示具体到期日期，原链接停止；已入用户相册副本不受影响 |
| 平台误识别/内容/规格错误 | 免费纠错，修复失败按平台失败退费；不占用户修改机会 |
| 用户希望换预设/商品 | 新报价主动购买；不能挪用旧付款 |

全部必需产物通过才给完整交付权益，主UI能逐项查看。退款处理中与最终到账区分，累计≤实付，手续费按真实通道账单。因设备保存问题不默认承诺退款或拒退，若应有相册功能在平台支持版本普遍不可用则属于服务问题，需修复/退款评估，不能一律归咎用户。

## 修改、Plus与成本

默认全自动；48小时内一次受限小修改仅限封面、允许顺序与不改变原声语义的显示文字，不增加媒体或重生演员。换台词、人物、生成路线属于新需求重新报价；商品变形/错误台词/规格缺陷属于平台纠错，不能伪装为用户付费修改。成功才耗用户机会，修复保留原合同与关联版本，失败按退款政策。领取默认交付后7天。

网页Plus承接精细版式、批量、自定义规格、品牌和文案深调。Plus是产品层级，是否订阅/单次收费另验证，不预设已批准的会员体系。基础小程序用户无需升级即可生成、查看、保存和售后。

成本按全部样例/任务记录：视觉/脚本规划、商品/人物参考、分镜生图、逐镜I2V或原生整片、声音、QC模型、后期/转码、存储/下载、修复/失败、退款及支持。另计免费识别/计划、可选预览和社区样例/审核，免费不等于零成本；视频付费任务须用户确认后才提交。单笔贡献=净收款减实际变动成本及分摊，不等于净利润。

按ExecutionVariantVersion＋实际模型/语言分层记录p50/p95成本、耗时、修复与退款；同商品对照逐镜和整片，不能先认定九宫格必然更便宜。未获得真实费率和含失败的基准前保持price=null、禁止售卖。平台可限制免费规划/样例额度，但不限制已购任务执行/领取，不把失败重复提交变成隐藏扣费。

## 自助运营与指标

官方10套/14变体逐一验收，社区每个可售变体采用同一配置、输入、许可、样例/30次基准、身份/声音、清单/节奏和成本门槛。未通过标未开放，不能把来源391配方一键转为可售。后台按模型/变体/语言查看失败、质量误放/误拒、支付、预算与投诉，支持精确暂停受影响新售；正常制作不依赖人工接单。

新增指标：识别精确率/覆盖/未知、商品身份缺陷误放/误拒、人物跨镜连续性、实声/字幕质量、原生/交付规格、10套/14变体完成度、完整自动交付与修复率、逐模型成本/预算超限、保存和社区有效复用。原生模型成功率、整包交付率、设备保存率分别统计。客户端事件不创造付款者或覆盖交付/售后判断；赛事有效数据按官方认可路径核验，抖音流水不自动计入支付宝赛事付款者。

公开案例需自有/单独授权；不要求为了领取素材去点赞/分享。相机/相册权限按需要请求，用户相册副本由本人管理。供内部排障的人工作业如发生须标记，不能用于证明自动化完成率。

## 社区方案的发布、费用与权益

P0暂按方案免费分享、使用时由平台就实际制作服务统一报价。方案发布费和方案许可费默认为0；制作是否提供免费额度及实际价格待成本验证，创作者样例/预览额度和超额费用必须先说明。社区作者不能直接修改已审方案的成交价。后续付费模板/分成/打赏/提现另立合同和结算需求，本版不显示未定义的收益入口。

官方10套由官方维护许可、适配和质量，不能依靠社区补足缺少的官方方案。社区作者提交配置、公开样例及素材许可承诺，平台审核并保留证据；检查可人工进行，不变成普通买家每单需人工审核/代做。用同款、收藏和允许范围内派生不赋予作者访问买家照片/识别档案/成品的权限。

方案许可在提交时明确：可否商业输出、可否派生、署名规则及字体/音乐等资源许可范围。未取得适当权限不能发布或用于收费输出，不能因作者勾选“开源”就省略第三方核验。公开样例另取图片/肖像/商标等适当权限，默认不把任何私人订单转公开素材。

普通下架停新单，旧单继续已冻结版本；违规资源/权利争议等强制禁用影响旧单时，通知并执行退款/补偿，不能静默换规格或强制顾客承担作者纠纷。发布、版本、许可、举报/申诉和处置留审计；必要合同凭据与私有照片分开，普通清理不能删除必要授权证据。

## 来源、人物与公开案例边界

来源文本/源码采用方式保留ClipForge/xixihhhh及固定提交/许可记录，源码和字体/音乐/人物/声音/商品样例权利分别登记。已有演示只证明文件和可见内容，不自动证明可商用或对应具体配方ID；生成式宣传样例须来自本产品可追溯执行计划，并单独取得公开权限。

AI人物是广告演绎，不伪装真人消费者、专家或长期体验者。价格/促销/实测/销量等事实从用户授权商家数据或可核资料取得，不能继承参考脚本话术；无来源省略或用中性CTA。普通用户不必为此填长表。

未付款照片/档案/预览默认24小时，已付款输入/档案默认7天覆盖修改窗口，高清产物自完整交付后7天。私有分镜图、人物/商品参考、供应商中间结果与缓存纳入相同生命周期；供应商留存限制/可删回执进入准入与隐私说明，不承诺服务端能删除买家相册副本。

公开社区样例另取明确授权，从审核批准起最多30天，以独立副本和独立对象登记持有，不延长私有输入保留期。作者可在发布记录撤回；撤回/到期/许可或资源失效先停止分发及新制作，再清理受控对象。私有自然到期保留有效的独立公开权，作者主动删除商品/账户则一并撤回；签名删除日志和备份重放保留原来源与冻结对象集合。费用和商业准入不因样例公开而自动开放，已售订单依原快照处理。

## v3.1 Codex费用与实例运营

成本按真实发生的推理/视觉、生成、后期、两次独立复核及最多一轮修复汇总，并分付费前获客成本和付费后履约成本。Skill预热不等于免费推理缓存，不预设KV命中/模型实例独占；模型费率、token预算与工具额度必须随报价冻结，进程重启/角色切换不清零。尚无真实费率，维持全部禁售。

付款前分析/规划结束释放实例；付款后按快照启动执行，不占用进程等付款或等用户下载。发布完整包后立即写回收事件，释放不删除7天领取作品；小改/免费平台纠错建新实例，已售权益不缩水、不因初始化再次扣用户费用。

任一复核失败/冲突/证据不足不得交付。剩余预算/截止内最多一轮修复，仍失败按原合同退款；工具UNKNOWN、回收失败和退款UNKNOWN分别处理。释放进程不代表取消供应商费用或支付，迟到结果归原意图对账。运行监控新增Skill错载、实例泄漏、跨单访问拒绝、审查旧hash、调用/token/复核成本与清理告警。
