## 1. 产品与用户闭环

一品成片是面向小商家的商品素材云服务，以支付宝小程序与抖音小程序为同级核心。用户拍3–5张商品照，多模态LLM自动识别商品和可见特征；用户选官方/社区方案及效果，确认整包清单与费用，云端完成图片、短片与文案，用户保存到相册。

用户不填写商品长表、不写提示词、不安排镜头、不逐项审稿。必要的身份、隐私、付款与相册授权仍由本人完成。输入不足在收费前补拍或改选，不把未知材质/成分/尺寸编成事实。

## 2. 当前冻结范围

需求v3.1共58项功能/58主验收：52项P0、4项P1、2项P2。完整P0包含双小程序、商品档案/身份锁、官方10套/至少14变体、三条产线、图片/视频/文案整包、按渠道交易/退款、相册恢复、基础社区与任务恢复。

十套官方风格保留各一个图文展示变体；另外四个生成式变体为轻奢细节·AI质感展示、清新日常·AI生活场景、竖版种草·AI单镜讲解、竖版种草·AI连续多镜。逐镜与连续整片均是P0，不能把“先做照片动效原型”称为完整首版。

P1：网页Plus、主动跨端绑定、多语言、A/B开头。P2：条件化高级方案、授权外部发布。评论、关注、聊天、榜单、作者付费模板和提现不构成本版依赖。

## 3. 设计与内容是两层

产品界面固定C「柚子创作社」v1.0：果橙、奶白、深绿墨、照片印样和清楚的作者行。23页面/交互单元、22类组件已经定义，3页有原始高保真参照。原始图不可覆盖，后续按tokens实现对比、比例和动态清单修正。

UI风格不强制改变生成素材风格。商品颜色、结构和包装由输入事实锁定，素材视觉采用用户选择的官方/社区方案。设计名“柚子创作社”不改产品名“一品成片”。

## 4. 开发方案

小程序首选Taro＋React＋TypeScript，共享页面/业务/组件，以两个宿主壳和适配器处理原生差异，G0双端实验后锁版本。后端推荐Node.js 24 LTS＋TypeScript＋Fastify模块化单体，独立Worker处理持久任务、供应商与FFmpeg；PostgreSQL承载业务与阶段队列，私有对象存储保存媒体。Redis不是首版正确性的依赖。

工程依赖已在[package.json](../../package.json)和 pnpm 锁文件中记录，原生 Node / PostgreSQL / Sharp / FFmpeg 已执行局部测试。双宿主实测、生产云资源、实际模型/费率、人物声音和交易资质仍待验证；锁定开发依赖不代表生产能力已准入。

one-tap-ads固定提交已核查，391条配方及案例提供创意与生成流程参考，不自动转成391套可售服务。上游本地页面状态、SQLite和浏览器执行不能作为产品核心履约机制；业务合同、持久任务、双小程序和消费者交易由本项目实现。

源码采用须记录固定版本、许可与修改边界；AGPL和第三方素材权利按[安全与许可文档](08-安全隐私与依赖许可.md)处理。研究样片不证明本产品已实现或有公开商用权利。
