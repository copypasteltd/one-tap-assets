| 来源 | 支持的设计判断 | 适用限制 |

| [Taro应用配置](https://docs.taro.zone/en/docs/app-config) | 跨宿主配置有差异，需要平台壳和适配器 | G0真机实验决定实际可用范围 |

| [Ajv JSON Schema版本](https://ajv.js.org/json-schema.html) | 2020-12使用专用Ajv实例，不与旧draft混用 | 响应序列化、类型生成同样要兼容实验 |

| [RFC 8785 JCS](https://datatracker.ietf.org/doc/html/rfc8785) | 稳定快照/计划使用规范化JSON再计算摘要 | 普通JSON键排序不等同于完整JCS，需兼容实现与向量校验 |
| [ffprobe](https://www.ffmpeg.org/ffprobe.html) | 结构化检测媒体流/编码/时长 | 不足以判断商品一致、中文可懂与授权 |
| [OSS私有文件URL](https://help.aliyun.com/en/oss/use-a-fixed-file-url-to-access-a-file) | 私有对象与授权访问方案 | 期限/撤销行为按实际SDK和权限配置实测 |
