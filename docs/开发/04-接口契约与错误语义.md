## 1. 通用协议

JSON请求/响应，UTF-8。普通请求用产品Bearer会话；会话从对应宿主临时凭证换取，不接受昵称/客户端自报openid。浏览公开目录允许匿名，携带商品/profile筛选时必须合法本人会话。管理与服务操作不混入买家token权限。

成功包：`{code:"OK", data:..., trace_id:"..."}`。失败包：`{code, message, retryable, trace_id, details:[{field,reason}]}`；不回原始供应商报文、堆栈、密钥或私有对象路径。202仅表示受理，必须已持久记录且可用资源ID查询。

列表默认20、最大100，返回`items,next_cursor`，游标含筛选/排序/归属绑定。时间为UTC ISO8601；金额分整数；未知金额为null且不可售，不以0替代。所有写入由服务端确定归属，路径对象逐项检查，不信任客户端tenant_id。

会话、私有数据和含短链响应使用`Cache-Control: private, no-store`，不进入共享CDN缓存；公共目录只缓存无用户信息的版本投影，停售/撤回及时失效，建报价/订单仍重新校验准入。档案DTO为买家可见投影，不暴露模型调试/凭证等内部字段；服务端完整档案另含实际模型/提示/校验版本及回执。

## 2. 幂等与乐观并发

会产生业务副作用的POST/PATCH/DELETE使用`Idempotency-Key`；收藏PUT/DELETE本身幂等。登录凭证交换、供应商支付回调有独立协议，不强迫外部平台传本项目幂等头。请求键绑定主体/租户、操作、目标与规范化body摘要；相同键不同摘要409，相同请求返回同资源与一致业务结果。

当前v1.1业务/管理契约、共享客户端和服务端统一要求8–128字符，允许`A-Z a-z 0-9 . _ : -`。UI原动作键可含`ui:`前缀，超长或非法键在写入前拒绝；同一次未知结果继续使用原键与原请求体。该修订只更新当前契约，不覆盖v1.0历史文件。

活动订单、支付、退款和供应商意图的永久业务唯一约束不能依赖短期HTTP幂等缓存。幂等记录的保留至少覆盖关联活动对象/重放窗口，敏感签名URL和token不直接明文缓存为长期响应；重放可返回同资源的新短期访问授权，不新建收费副作用。

草稿PATCH/照片替换/识别纠错提交`expected_revision`，过期409，重新获取后由用户选择保留/修改，不静默覆盖。已发布版本只读；换照片/效果后旧计划与报价不可继续使用。

## 3. 输入上传与分析

`POST /products`建立无商品事实表单的草稿；`POST /assets`申请仅限一个对象/大小/用途的上传授权；客户端上传后`POST /assets/{asset_id}/complete`由后端核对象存在、真实类型、大小/hash、解码、旋转与EXIF后才标READY。客户端自报上传成功不是证据。

资产purpose区分商品照片、作者权利证明、售后和举报证据；商品照片必须绑定本人product_id，其他证明只走对应私有用途，不能绑定为商品照或公开样例。公开样例与作者私有样例分别通过受控媒体接口取短链；不是通用任意对象读取接口。

`PUT /products/{product_id}/photos`提交3–5个本人READY照片及expected_revision，生成照片版本。`POST /products/{product_id}/analyses`只引用此版本；返回analysis_id，客户端GET轮询。识别JSON必须过字段/证据/事实规则，不让客户端直接POST最终档案冒充LLM结果。

纠错入口可提供候选/补拍和可选短说明；每个修改保留来源，不变成强制填材质/参数。创建计划前`input-check`验证具体变体输入与实际能力，失败清楚给补拍或改选。

## 4. 计划、报价与订单

Plan READY说明脚本/时间轴/能力计划可用，未表示媒体已生成。公开PlanView提供必要摘要与plan_hash，不暴露供应商凭证/内部成本台账。Quote冻结完整快照，前台只显示效果/声音、清单、金额、预计区间与服务截止规则。

可选本人预览使用同版plan_id/plan_hash，受每日5个新预览的原子额度限制；获取已有结果/短链不重复扣额度，不用预览代替正式交付或提前发起隐形收费视频。

`POST /quotes`只接受计划ID/hash，不接受客户端价格/模型参数。`POST /orders`消费有效quote并绑定当前app/channel，返回order_id与付款动作状态；`POST /orders/{order_id}/payment-attempts`仅创建/恢复该原单的获准支付动作，先查未知旧attempt，不能无脑再开收款单。

报价15分钟失效；建单另有明确payable_until。晚到支付确认仍记录真实资金：若已不能按原合同受理，进入异常/原渠道退款，不能简单丢弃回调并让已付用户失去权益。接口取消、退款、修改均查询原单、加锁并按业务合法分支执行。

## 5. 媒体与保存

`GET /orders/{order_id}/deliverables`仅在完整交付与合法权益下返回有序清单/文案，不返回可长期裸读的URL。`POST /deliverables/{deliverable_id}/download-link`逐次检查归属/退款/领取期限，签发5分钟短链；过期重新取，不重新扣制作费。

保存会话记录本安装媒体/attempt/回调，服务端仅作体验数据；不能通过客户端`SAVED`改变DELIVERED、付款或退款。UNKNOWN不当作确定失败盲重存。回执被重复上报不增加成功数或写重复订单事件。

## 6. 社区与治理

草稿请求是受控配置值而非任意schema/脚本。样例生成默认私有，发布另需授权、资源许可和准入证据。submit是进入审核，不直接公开；审核/发布/停售/申诉决策仅运营角色。普通作者可查看自己的审核状态和公开版本，不获取买家档案或调试信息。

收藏、派生、举报与申诉各有资源与权限；父版本不允许派生时拒绝。资源被强制禁用影响旧单时通过处置流程通知/退款，不在目录接口偷偷替换版本。

## 7. HTTP与业务错误

| HTTP | code例 | 含义与恢复 |
| --- | --- | --- |
| 400 | INVALID_REQUEST | 结构/字段/格式错误，修正输入 |
| 401 | SESSION_REQUIRED / SESSION_EXPIRED | 取得合法会话，不无限重放付款 |
| 403/404 | FORBIDDEN / NOT_FOUND | 无权对象可统一404，避免资源枚举 |
| 409 | IDEMPOTENCY_CONFLICT / REVISION_CONFLICT / STATE_CONFLICT | 查原资源或刷新版本，不自动新开单 |
| 410 | QUOTE_EXPIRED / DELIVERY_EXPIRED | 按权益状态更新报价或查看帮助 |
| 413 | INPUT_TOO_LARGE | 收费前拒绝/替换照片 |
| 422 | INPUT_INSUFFICIENT / VARIANT_UNAVAILABLE / PLAN_BLOCKED | 补拍/改选；未知材质不要求填表 |
| 429 | RATE_LIMITED | 提供Retry-After；免费规划限流不取消已付任务权益 |
| 502/503 | DEPENDENCY_UNAVAILABLE / SERVICE_UNAVAILABLE | 有界重试；付费提交未知必须查原任务 |

`retryable=true`只说明该类操作可恢复，不意味着可以换幂等键重新付费。客户端按操作类型决定查询/重试/提示。服务端trace_id贯穿计划、订单、阶段、供应商、QC与退款。

## 8. 契约实现与兼容性

OpenAPI按[3.1.1规范](https://spec.openapis.org/oas/v3.1.1.html)书写，JSON Schema采用2020-12。路径参数、响应schema、枚举与操作ID必须核验；JSON格式有效不等于权限/事务正确。新增可选字段一般兼容，删字段/改含义/枚举收紧需版本和客户端支持策略。

支付回调保留原始字节，按对应通道SDK/正式协议验签与查单；OpenAPI仅声明可接受的原始媒介，不假造统一签名字段或把普通Bearer当通道验签。具体支付原生报文与模型提交协议在适配器合同另行冻结。

## 9. 内部管理合同

[管理OpenAPI](../../assets/development/v1.1/contracts/management-openapi.json)使用`/v1/internal/p01`，独立管理身份audience/issuer与逐动作权限，产品会话不能访问。包括审核队列/决定/发布、变体准入/停售、模型停用、举报决定、原单脱敏trace、平台免费纠错、原渠道补偿、供应商对账、聚合指标和清理协调。全部尚未实现。

管理写操作同样幂等、带理由/证据和审计。角色按moderator/registry/support/finance/operator/privacy分权；读原单事件不自动得到私图读取权。异步动作按action_id查询；人工操作不能直接把UNKNOWN改为成功或绕过预算/权利/QC。模型/资源/费率/售价证据初始登记走受控版本配置/迁移，变更形成新版本/报价，不覆盖已售合同。
