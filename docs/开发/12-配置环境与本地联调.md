## 1. 当前可执行与未来目标

## 2. 配置清单

[.env.example](../../.env.example)只列键、空凭证与保守开关。复制为本项目`.env.local`后按环境注入，不提交真实内容；测试日志禁止打印完整环境。秘密管理与部署配置可替代本地文件，但必须同等验证。

| 类别 | 关键配置 | 启动/销售规则 |
| --- | --- | --- |
| 基础 | APP_ENV、HOST、PORT、PUBLIC_BASE_URL、RUNTIME_ROOT | 本地默认回环；路径解析后必须在项目runtime内 |
| 数据 | DATABASE_URL、DB_TLS_MODE | 真实API必须可连且迁移兼容；测试拒绝生产目标 |
| 存储 | STORAGE_DRIVER/ENDPOINT/REGION/BUCKET及安全注入凭证 | 生产只准入私有对象驱动，本地文件不冒充云存储 |
| 宿主 | ALIPAY_APP_ID、DOUYIN_APP_ID及服务端秘密 | 两端隔离，未配置端不展示获准能力 |
| 交易 | PAYMENTS_ENABLED、两通道商户/验签/回调配置 | 默认false；缺渠道准入禁止建收费订单 |
| 模型 | PROVIDER_GENERATION_ENABLED、端点/密钥、模型注册表版本 | 默认false；模型/费率/声音/参考未准入禁售 |
| 内容 | COMMUNITY_PUBLISHING_ENABLED、PRESET_REGISTRY_PATH | 默认false；不能绕过审核/能力门禁 |
| 预算 | 有界并发、每单/样例配额、故障修复政策版本 | 已售预算/截止从快照取，不用环境变量改旧单 |
| 观测 | LOG_LEVEL、观测端点/凭证 | 脱敏；不得采集原图/音视频或私有URL |

TTL、帧规格、每单预算和售后属于版本政策/合同，不应塞入可随部署悄悄改变旧订单的全局.env。全局开关只能停新售/控制安全执行；旧单处置独立留记录。

## 3. 本地联调顺序

先纯规则/schema→独立原生测试库的迁移/事务→私有对象上传确认→真实视觉分析→计划与禁售报价→已获准测试支付/履约→三路线/后期/QC→两宿主保存→社区。网络依赖启用前校验目标、账户、预算、授权素材和环境隔离，按实际任务授权执行。

mock仅用于隔离失败、宿主适配和纯业务验证；显式`provider_mode=mock`并保留证据标签，生产启动拒绝。mock订单、素材和金额不能进真实账本/公开样例。没有模型凭证时返回依赖不可用，而不是返回样片作为“你的成片”。

所有缓存/临时文件/浏览器profile/原生媒体工作目录/测试下载设在项目runtime；命令子进程同样设置。系统依赖可读取已安装路径，但本任务不向项目外写文件。浏览器联调完关闭本次不用的标签页和资源。

## 4. 本轮文档检查命令

从项目根目录使用已安装的原生Python及jsonschema分别执行；核验器显式检查本项目UTC日期/HTTPS格式，不依赖可选格式插件是否安装：

```powershell
python -B -X utf8 scripts/生成Codex开发契约.py
python -B -X utf8 scripts/核验Codex方案.py
python -X utf8 scripts/设计选型/定型C设计基线.py --verify
```

第一项生成当前v1.1设计合同，第二项覆盖既有合同检查及v3.1/Codex/Skill关联，第三项独立核验C设计留存，均不调用模型或收费服务。`scripts/生成开发契约.py`仅保留为v1.0历史来源，不用它生成当前合同；修改生成源后重生成并核验，不能只手改输出导致下次丢失。

脚本中断/失败需报告实际结果，不能因JSON可读就声称产品通过；新的运行栈启动命令待对应工作包真实实现后另加并实测。
