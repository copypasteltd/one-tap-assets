## 定型内容

主标志使用原选定的软萌果橙相机：单片叶子、友善表情、深绿播放窗口和右侧镜头。原始1254×1254PNG及提示词原样留存。主图仅清除孤立极低透明度边缘杂点，共7600个Alpha像素变化，保留图形的RGB完全一致；透明2048版为放大导出，原生细节以1254源图为准。

## 复导出和核对

生成目录为 `output/imagegen/2026-11-01-citrus-director-final/`，正式归档为 `assets/brand/citrus-director/v1.0.0/`。在项目根目录使用原生Python和已有依赖；PDF创建前按当前PDF技能执行一次生成登记，再运行：

```text
python -B -X utf8 scripts/design/build-citrus-brand.py
python -B -X utf8 scripts/design/create-citrus-brand-guide.py
pdftoppm -png -scale-to 1600 output/pdf/一品成片-柚子小导-品牌手册-v1.0.pdf runtime/tmp/pdfs/citrus-director-v1/page
```

实际查看最终8页PNG、主总览、透明/单色/反白、大小图标与上线物料后，再执行：

```text
python -B -X utf8 scripts/design/finalize-citrus-brand.py --visually-inspected
```

该步骤核对原图与RGB、Alpha清理、22路径SVG及单色填充、图片解码和尺寸、透明边缘、ICO/GIF、9色ASE、8页PDF及正文/副本、70处本地HTML/Markdown链接、ZIP内CRC和逐文件SHA256。手册采用不同PostScript字体名区分450/750字重，避免PDF字体缓存合并。OFL许可与来源随包保留。

本轮没有新增生图调用，没有浏览器、Docker/WSL/虚拟机或子代理；不运行无关业务构建和全面测试。完成后中英README、状态、更新记录与仓库同步。
