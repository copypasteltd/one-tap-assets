2026-10-27。视觉基线继续为`YPCC-DS-C-1.0.0`；本轮增加后台Codex执行与交叉核验/释放要求，不修改原始稿、tokens、25份冻结文件、归档包及原50项设计映射。新增8项的兼容映射另存[设计补充映射](../../assets/development/v1.1/design-compatibility.json)。

## 用户仍只拍照选方案

主路径为拍照→自动识别→选官方/社区方案→确认清单/报价并按需付款→自动制作→检查素材→完整素材列表→保存相册。内容策划、工具调用、双复核和进程清理均在后台；不得把模型、Skill路径、上下文、token计数或逐阶段技术审批加入小程序必经流程。

进度复用既有“整理商品信息、制作素材、完善声音与字幕、检查素材”等业务文案；保留按真实后台状态推进、失败可解释、关闭小程序继续执行的要求。只有真实发布manifest才显示完成，不根据Agent输出的“完成”文字提前成功。相册保存仍按逐项回调区分待保存/成功/失败/未知。

## 交付、回收和售后

交付卡继续显示素材清单及领取截止；实例回收不出现“作品已删除”的错误文案，不让客户等待后台进程释放才领取。交付后默认7天作品可领取；小改/平台纠错在新实例执行并显示新版本，历史合同与免费纠错权益不变。

方案详情可用用户可理解的方式说明“含自动检查”，不能承诺零失真/必爆/绝对正确。引用社区作者、风格、节奏、规格与AI演绎标识沿用C基线；后端Skill不得覆盖字体/颜色token或另建聊天界面。新增8项均映射既有页面/组件，后台事实复核与清理运维没有强制新增面向买家的页面。
