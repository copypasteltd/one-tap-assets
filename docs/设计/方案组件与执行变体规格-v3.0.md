# 一品成片：方案组件与执行变体规格

P01｜v3.0｜2026-10-27｜需求设计，未实现。本文细化F04/F19/F27及F32—F50，主需求见 [PRD](../01-产品需求PRD.md)。配置权威入口为 [presets.v3.json](../../assets/presets/presets.v3.json)，映射副本为 [云端方案映射v3](../../assets/blueprints/云端方案映射.v3.json)。

## 1. 方案、组件和变体如何组合

用户选择的是可理解的效果，例如“轻奢细节·AI质感展示”，而不是模型/seed/工作流。后台由三层组合：商品事实决定可以说什么和展示什么；方案版本决定叙事、视觉、镜头和输出；执行变体决定引擎、人物/声音、时限、资源与价格。

| 层 | 内容 | 发布规则 |
| --- | --- | --- |
| 来源目录 | 仓库固定提交391配方及脚本/视觉/合成基元 | 只读研究，保留来源；不自动上架 |
| 受控组件 | 叙事、画面形态、运镜、Look、人物、声音、字幕、音乐和版式 | 每个组件有版本/许可/能力与质量状态 |
| 方案版本 | 品牌风格、节奏、事实策略、完整输出槽位和允许的变体 | 官方与社区同schema，审核后不可变 |
| 执行变体 | 具体能力组合、输入、原生生成和交付规格、预算与失败合同 | 独立验收/定价，未准入不可购买 |
| 订单快照 | 本商品事实/锁、具体台词/分镜/参考策略、模型/费率、资源、期限与清单 | 报价绑定；不从前端全局设置取值 |

社区作者可以组合准入组件、填写创意描述和发布自己的授权样例；不能给组件赋予不存在的能力，不能更换模型密钥、执行任意代码/URL或读取买家资产。创意描述作为不可信输入，服从事实和平台规则。

## 2. 来源内容的规范词表

| 维度 | v3规范 | 适配要求 |
| --- | --- | --- |
| 浏览组 | 商品展示、人物讲解、剧情叙事、生活种草、促销转化、创意视觉 | 作为发现标签，不据此决定引擎 |
| 商品类目 | beauty、food、home、fashion、digital、unknown | tech映射digital；unknown使用中性参考，不默认美妆 |
| 叙事 | pain_point、scenario、comparison、story、drama、reversal、interview、unboxing、product_personification、talking_head、product_showcase、feature_cards | pain-point/pain_point、scene/scenario等显式归一；product_pov必须逐方案决定展示或拟人，不盲目继承原长提示 |
| 画面形态 | product_closeup、graphic_montage、scene_demo、live_presenter | 是素材策略；scene_grow仍需要场景生成能力，不能只凭graphic_montage走纯照片 |
| 运镜 | 来源22种意图＋平台确定性照片运动组件 | AI运镜为生成要求而非保证；照片平移不宣传为真实360度转台 |
| Look | 来源14种光线/背景/色彩/机位描述 | 391配方仅使用8种；原图版取版式/背景意图，不能改商品真实色或靠Look假定真实LUT已应用 |
| 字幕/合成 | standard、bold、minimal、karaoke；音乐情绪/音量/ducking、商品卡、画幅 | 必须编译成后期参数；不能只在网页预填一次 |
| 人物 | 来源6套设定及后续平台准入人物版本 | 外观/口吻不代表真实代言人或已授权声线；样例与人物权利分别登记 |

原391条没有总时长、344条未显式给合成质量。发布版本需补全，禁止依赖当前应用默认值。规范化后有385组不含创意提示的参数、391组含提示的组合，参数复用不意味着叙事可互换，也不代表385套独立执行引擎。

## 3. 首版14个官方执行变体

官方ID/名称/图片数量/视频时长沿用v2.1，方案版本升3.0.0。每个变体都交完整图片包、1个短片、文案和manifest；生成式变体不是只追加一个供应商视频URL。表中ID与JSON逐一对应。

| 方案ID与名称 | 基础变体ID后缀 | 图片/视频 | 具体来源蓝本 |
| --- | --- | --- | --- |
| minimal-clean 极简纯净 | .photo-layout | 4图＋10秒 | bullet_time_white、turntable_hero：浅底、主体与极少文字 |
| warm-handmade 自然手作 | .photo-layout | 5图＋15秒 | craft_hands、cottage_craft：暖色和细节；不继承无证据的制作过程 |
| quiet-luxury 轻奢细节 | .photo-layout | 5图＋15秒 | macro_texture、luxury_hero：灰调、微距和长停留 |
| fresh-daily 清新日常 | .photo-layout | 4图＋12秒 | lifestyle_seed、day_in_life：明亮、轻快、有序展示 |
| appetite-flash 食欲快闪 | .photo-layout | 4图＋10秒 | food_crave、pack_flatlay：近景、俯拍与快节奏 |
| home-calm 家居留白 | .photo-layout | 5图＋18秒 | ambiance_mood：自然色、留白与舒缓停留 |
| feature-cards 特征卡片 | .photo-layout | 5图＋15秒 | three_reasons、slide_deck、clean_label：有证据的信息点 |
| color-pop 色彩撞击 | .photo-layout | 3图＋8秒 | pack_flatlay、flash_sale：高对比图形；无活动信息不写价格/倒计时 |
| launch-story 上新叙事 | .photo-layout | 5图＋20秒 | new_drop、ritual_unboxing：章节顺序；不编新品差异/拆封事实 |
| portrait-social 竖版种草 | .photo-layout | 3图＋15秒 | presenter_talk、ai_ugc_actor：借鉴短句节奏，基础变体不冒称人物出镜 |

基础变体完整ID为方案ID＋表内后缀。最少3张清晰同商品照片可用，推荐正面整体/斜侧/真实细节；不足的新角度用合同允许的裁切/复用，不生成隐藏结构。

| 生成式变体完整ID | 内容与总时长 | 图包与声音 | 必须验证的能力 |
| --- | --- | --- | --- |
| quiet-luxury.ai-detail | 商品质感/微距逐镜，15秒 | 5张图片，默认无对白、许可音乐或合同静音 | 商品关键帧/I2V；材质、包装、标识跨帧稳定；不用未知背面 |
| fresh-daily.ai-scene | 商品融入生活环境，12秒 | 4张图片，默认无对白 | 生成周边场景并锁商品；合理比例/使用方式，默认不生成清晰人脸 |
| portrait-social.ai-presenter-single | 一段中文AI持物讲解，15秒 | 3张图片，中文原生语音＋实际音轨字幕 | 准入人物/声音、正确持物、可懂度/口型、保护原声 |
| portrait-social.ai-presenter-multi | 中文AI连续多镜广告，15秒 | 3张图片，中文原生语音＋后期字幕 | 统一参考、时间码、多参考整片、跨镜商品/人物稳定与后期 |

每个生成变体的3–5张照片仍需通过具体输入充分性。只拍正面却要求环绕、包装遮挡或手持比例不可判定时，在付费前补拍/改选；不让用户填材质、尺寸或长提示词。平台提供默认人物/声音/场景；买家不必提交真人照或语音。

原生多镜可用2–4个受控镜头角色形成开头、商品动作、讲解和收尾，具体镜头数受台词、模型与参考额度约束；15秒不是固定四镜保证。礼盒、配件和真实体验只有相应事实才能出现。18/20秒等后续生成变体须另行匹配时长能力，不沿用演示15秒截短履约。

## 4. 版本字段与默认值

| 字段 | 必填内容 | 未就绪处理 |
| --- | --- | --- |
| 标识/状态 | preset_id/version、variant_id/version、作者/来源链、review、sale_enabled | DESIGN/未审均不报价 |
| 创意组件 | 规范叙事、形态、Look/运镜/字幕/合成及版本；来源提示的使用限制 | 默认值在发布时冻结，非浏览器全局 |
| 输入/锁 | 3–5照片、角色/关键结构覆盖、ProductProfile/IdentityLock版本与证据 | 输入不充分先补拍或明确改选 |
| 声音 | none/native_speech/受控TTS、语言、动作声、字幕对齐、音乐/ducking | 讲解缺声不转静音，ASMR未验证不售 |
| 输出 | 逐槽位尺寸/格式/排序，视频总帧数/编码，文案/manifest | 不以九宫格/视频截图冒充正式图片包 |
| 模型/资源 | 原生规格、实际模型/能力/费率快照，人物/字体/音乐资源许可 | 任一必需引用缺失不可发布 |
| SLO/成本 | 预计区间、硬截止、最大修复轮次、逐节点和整单追加付费预算 | 值未验证/未定价不可售，不用无限重试 |
| 质量/样例 | ≥30次整包基准、失败/成本记录、身份/声音质量门槛 | 不把4条上游样片当自身验证 |

JSON内仍为DESIGN、sale_enabled=false、price_fen=null、模型/音乐/字体待准入。这是明确的设计状态；schema不能靠把这些null字段强转true进入售卖。生成脚本只把来源组件写为研究意图，尤其source_camera_plan/source_script_hint不能直接越过商品锁执行。

## 5. 商品锁、脚本与参考帧合同

`ProductIdentityLock` 的主字段为 `product_form/package_form/count_unit/structural_anchors/colors/text_regions/accessories/evidence_refs/unknowns`。值来自本人当前档案/照片，不用模型生成的杯装/礼盒回填。无法稳定显示的小字用真实商品图层/有证据的构图，不能“纠正”为猜测品牌。

`ScriptPlanVersion` 每镜至少含shot_id/role/start_frame/end_frame/transition_frames/fact_refs/visual_source/character_refs/camera_intent/dialogue/caption/audio_policy。总帧数等于合同，转场重叠计入；报价前完成文字/计划校验，付费画面生成在用户确认后执行。规则文案回退不能改变已售有声/人物合同。

多格图是可选参考策略，必须检查裁图索引、去缝、安全区域与每格有效像素。仓库9镜上限只是该实现约束；实际模型允许多少参考需当前注册表验证，人物图也计数。每个关键帧先验商品与人物，失败不继续花视频费。模型/参考策略变更须在报价前完成或重新报价。

## 6. 声音、后期和规格

PHOTO_LAYOUT以原图版式和时间轴文字为主，可许可音乐或合同静音。AI场景/质感可无对白，但动作声若不是合同必交则不宣传。人物变体P0需要中文原生语音；没有原生语音能力的供应商不能通过此变体准入，后续TTS/口型方案须另评测，不把任意音轨覆盖当兼容。

REFERENCE_FILM生成结果必须进入显式后期：保留原声 → 对齐/烧录已选字幕 → AI演绎标识 → 许可音乐与ducking → 商品卡/封面 → 规格化 → 全包QC。Look必须与发布版本一致，不能保留原接口默认手机感而出售影棚效果。

交付视频1080×1920/30fps/H.264/yuv420p，时长±1帧；图片按原槽位PNG。原生720p/24fps与交付1080p/30fps分开记录，不宣传转码即原生高清；必须另满足主体清晰度和语音完整性。原始生成时长需预留合同允许的停留/裁切余量，不截断台词凑帧数。

## 7. 输入条件化的高级目录

| 方案类型 | 额外前提 | 缺失时 |
| --- | --- | --- |
| 试衣/穿搭 | 允许使用的人物/衣物参考、衣物图案与结构/遮挡评测 | 不作为普通图文变体承诺 |
| 房改/空间预览 | 用户主动选择并提交房间照、空间/比例能力 | 普通买家不需要拍房间；只提供通用展示 |
| ASMR/开箱原声 | 同步开合/倾倒等声画能力与真实包装内容 | 无音乐不等于ASMR，不虚构附件 |
| 测评/账单/长期体验/访谈/专家 | 真实资料、授权与可核事实 | 禁止AI画面伪装实测/消费者或专家背书 |
| 促销/价格/新品差异 | 已授权有效商家数据或可核证据 | 省略价格/倒计时，用中性CTA，不强迫补表 |

这些条件可体现在社区准入与推荐过滤，不能让热门配方绕过能力/证据门槛。风格可复用，依赖的事实不可复用。

## 8. 时限、修复与发布门槛

初始设计：PHOTO_LAYOUT p95≤120秒/截止600秒；PER_SHOT_AI p95≤900秒/截止1800秒；REFERENCE_FILM p95≤1800秒/截止3600秒。从后端确认付款且必要输入具备的可履约时刻固定，包含排队、供应商、下载、后期、QC和修复，不因重启延长。可售版本须在自身真实基准和容量限制下冻结预计区间及硬截止；修订新版本，不追改旧单。

最多一轮修复，每个受影响节点最多一次额外生成，并受整单追加费用上限。多个镜头失败不能各自无限触发整片重买；UNKNOWN先查原任务。无法在预算/期限内完成整套则失败退款，不交局部包，不从AI版本静默降级为图文。

每个变体至少30次有效输入整包执行，包含失败，14个变体至少420次。AI商品锁/声音还需独立负例与标注集，阈值和结果随模型/资源/检测政策版本保存。公开样例另有权利与质量审核；通过一条最漂亮的样片不构成上架证据。
