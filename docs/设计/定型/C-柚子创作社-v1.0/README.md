## 已有图与规格的界限

已有高保真图：拍照制作首页、方案社区、素材领取，共3页，全部来自用户选定的同一张C原始图。其余20个交互单元已形成布局、字段、动作和状态规范，尚未逐页出高保真图，也尚未实现。

后续实现依次读：v3主需求 → 本定型规范 → tokens与注册表 → 原始图。原始图表达风格；正文与tokens校正可读性、视频比例、导航和真实业务状态。不能将生成图中的示例文字、虚构商品或图标失真作为生产事实。
