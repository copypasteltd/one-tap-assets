# 04 · 全流程状态与文案

以下为显示层语义，不自行创建或覆盖服务端业务状态枚举。实现时把服务端状态映射到这些页面表达；状态来源、订单权益和期限仍遵循v3.0。模板中的花括号必须替换为真实数据，缺失时不以虚构数字补位。

## 1. 文案原则

动作名称前后一致：拍照做素材、识别并选方案、用这个方案、确认并支付、保存整套素材、继续保存未完成项、复制文案。用“商品”“方案”“效果”“素材”表达用户理解的对象，不把引擎、模型、schema、API等内部名放进普通流程。

语气友好直接，错误说明原因并指向恢复动作。不给“秒出”“一定更好卖”“永久免费”等未经验证的承诺；不捏造使用人数、销量、认证、售价或评价。AI人物标广告演绎，不写成真实买家体验。

## 2. 拍照、上传与识别

| 状态 | 页面表达 | 主动作/恢复 |
| --- | --- | --- |
| 首次 | 拍3–5张，自动识别商品与特点 | 拍照做素材 |
| 输入提示 | 拍清整体、换个角度，再补一张细节 | 拍照/从相册选择 |
| 本地未上传 | 照片已选，等待上传 | 上传；不标已保存到云端 |
| 部分上传失败 | {n}张已上传，{m}张未完成 | 重试未完成；保留成功项 |
| 模糊/反光 | 这张细节看不清，换个角度再拍一张 | 补拍这张 |
| 多商品冲突 | 照片里可能有不同商品，请选定本次要制作的商品 | 选主体/移除无关照片 |
| 分析中 | 正在识别商品和可见细节 | 可离开；草稿真实持久化后才承诺可找回 |
| 完成 | 已识别：{name} · {visible_feature} | 选方案；次动作识别有误 |
| 类别不确定但可用 | 已整理可见外观，可先看看通用方案 | 看可做方案；不冒称精准识别 |
| 视觉服务失败 | 暂时没能完成识别，已保留上传成功的照片 | 重试识别；不进入收费 |

未知材质/成分/尺寸不展示必填红星，不要求用户补全。纠错是可选入口，只修正有依据的内容或补拍。识别失败与“商品类型较宽泛”是不同情况，不能用后者掩盖调用失败。

## 3. 方案与报价

方案卡：`{preset_name}`、`官方 / {author_name}`、`{image_count}图 · {video_seconds}秒`、`{effect_label}`。完整清单与人物/声音在详情说明，当前变体切换后同步改变，不能继续沿用旧价格。

无适配：“这些照片暂时不适合当前效果，可补拍整体照片或换一个可做方案。”未开放：“该效果暂未开放制作，可继续浏览样例。”社区空态：“暂时没有符合筛选的方案，试试其他风格。”样例：“方案样例，最终以你的商品照片制作。”

报价页先显示“正在整理本套素材与费用”，未取得有效报价不允许支付。有效期15分钟来自当前需求；显示真实失效时刻/剩余时间，不用于营销制造紧迫感。照片、档案、方案或效果变更后重新报价。

付费主动作：`确认并支付 ¥{total}`；合法免费合同：`确认制作`。金额未配置/能力未准入时显示“暂未开放制作”，不能填0元、9.9元等占位进入收费。预计区间和硬截止来自本订单，设计初始SLO不能直接当所有变体的已验证承诺。

## 4. 支付与退款

| 状态 | 用户看到的内容 | 合法动作 |
| --- | --- | --- |
| 用户取消 | 尚未完成付款，已保留本次方案 | 继续付款，前提报价仍有效 |
| 前端返回成功，后端核验中 | 正在确认付款结果 | 查询原订单；不重复付 |
| 结果未知 | 付款结果暂未确认，请先查询本订单 | 查询付款结果、订单帮助 |
| 服务端验付成功 | 付款已确认，正在准备制作 | 查看制作 |
| 报价过期 | 本次报价已过期，需要重新确认费用 | 更新报价；不改变已付款合同 |
| 平台无法完整制作 | 这套素材未能完整完成，按原订单处理退款 | 查看退款详情 |
| 退款申请/处理/到账 | 分别显示已申请、处理中、已到账等真实回执 | 查询退款；不提前声称到账 |

所有查单和退款均沿原交易渠道。前端重复点击、离页或回调丢失不能新建收费订单解决。用户仅拒绝相册权限时进入保存恢复，不标成云端制作失败或自动重收费。

## 5. 云端制作

阶段候选为排队、准备画面、生成图片/视频、整理声音字幕、检查整套素材。当前路线不需要的阶段不强行展示为已执行；底层节点可合并成用户能理解的步骤。

显示“当前：{stage}”“预计{range}”“最晚处理至{deadline}”，仅使用服务端已冻结/可用数据。缺少精确进度时显示阶段与已用时间，不用定时器匀速增长到99%。原图、逐镜AI、连续多镜有不同时间，不统一承诺120秒。

自动修复：“正在修复未通过检查的素材，仍按本次订单处理。”修复包含在原截止与预算，不重置倒计时，不展示无限重试按钮。供应商结果不明先查询原任务，不让用户再次付费生成。

退出提示：“你可以离开，制作会继续，稍后到我的素材查看。”仅指已受理的服务端任务；不得将此承诺用于尚未上传的本地照片或手机相册写入。

## 6. 交付、预览与文案

整包验收通过才显示“素材已就绪”“{n}张图片 · {m}条视频”。只成功几项时仍是制作/修复或失败状态，不能称已完成并让用户接受缩水清单。

片段、图片、主图、角度、细节、海报按真实槽位显示；方案不含某槽位则不虚构。`AI场景`说明环境生成，`AI讲解`说明人物/声音演绎，成品按内容政策保留AI标识。

素材领取默认交付后7天，以真实订单到期时刻显示“可领取至{time}”；签名链接到期但权益未到期时刷新链接，不误称作品已删除。云端权益到期则说明并按既有政策提供帮助；不承诺无期限保存。

复制成功：“文案已复制”；复制失败：“未能复制，请重试”。复制不计入相册媒体数，也不代表已经发布到抖音或上架商品。

## 7. 相册保存

| 状态 | 固定表达 | 动作 |
| --- | --- | --- |
| 未授权 | 保存这些图片和视频需要相册权限 | 继续并触发系统授权；可取消 |
| 下载中 | 正在下载 {i}/{total} | 可暂停/离开；说明客户端限制 |
| 已确认部分成功 | 已确认保存{ok}/{total}项 | 继续保存未完成项 |
| 拒权 | 尚未获得保存权限，云端素材仍可领取 | 按宿主能力打开设置或重试 |
| 空间不足 | 手机存储空间不足，已保留保存进度 | 清理后继续未完成项 |
| 下载链接失效 | 下载链接需要刷新，素材权益仍有效 | 获取新链接后只续存未完成项 |
| 回调未知 | {n}项保存结果未确认，可能已经保存，请先检查相册 | 检查后明确再存；不自动重复 |
| 全部确认成功 | 已确认保存{total}项到相册 | 完成；可明确再存一份 |
| 离页/后台暂停 | 保存可能暂停，回到本页可继续未完成项 | 恢复逐项状态 |

默认跳过当前安装环境已确认保存项；不承诺系统级绝对去重。保存无需重新制作、无需再次购买，不强制分享、关注或升级Plus。

## 8. 社区、作者与售后

作者输入只在创作流程出现，普通买家仍免填表。草稿：“保存后可继续完善”；缺许可：“请补充样例和资源的使用权说明”；审核中：“该版本审核中，尚未公开”；退回：“请处理以下问题后重新提交”；已发布：“当前公开版本{version}”。

派生前展示作者和许可，不能用“用同款”把他人方案改名当原创。旧单绑定原版本，新版不能覆盖旧合同。普通下架说明新制作不可用；强制禁用对旧单的处理遵循通知和退款政策。

交付后小修改：“48小时内可做一次允许的小修改”，实际依据服务端窗口和次数；平台识别/商品/规格错误是独立纠错，不消耗用户机会。不把换商品、换人物或重写口播伪装成一次免费小修改。

## 9. 事件与隐私

设计事件关注真实入口、识别结果、方案/效果选择、确认与付款、完整交付、保存成功/未知和社区发布。事件参数使用必要的ID与状态，禁止把原始照片、完整档案、付款凭证、私有URL和自由文本直接发到分析日志。统计不能将“开始保存”记为“全部保存成功”。
