# 01 · 视觉与布局规范

设计基线`YPCC-DS-C-1.0.0`。数值来源：[design-tokens.json](../../../../assets/design/柚子创作社/v1.0/design-tokens.json)。本文件所述尺寸为设计逻辑像素，不是生成图片像素；375逻辑宽度仅为基准，不锁死宿主屏幕尺寸。

## 1. 核心色与角色

| 名称 | 值 | 用途 |
| --- | --- | --- |
| 果橙 | `#FF7948` | 主行动填色、少量选中提示、品牌点缀 |
| 奶白 | `#FFFAEE` | 页面底色、照片印样周围的温和留白 |
| 深绿墨 | `#263B32` | 正文、标题、主按钮文字与图标 |
| 浅薄荷 | `#CFE9D6` | 完成状态的轻背景、次级行动背景 |
| 柚黄 | `#FFD766` | 首页短划线、AI提示/风格标签的有限背景 |

功能色不改变品牌：白`#FFFFFF`作卡片；正文次色`#5A6A61`；边线`#D8E0D8`；深橙`#C04420`作链接/选中描边；浅橙`#FFF0E8`作轻选中底。错误用`#B83232 / #FFF0EE`，成功用`#236449 / #EAF5ED`，注意用`#6B4B0C / #FFF3CF`。状态必须同时有图标/文字，不只凭红绿区分。

### 对比与行动色

果橙上白字的数学对比度约2.60，不作为普通按钮文字。主按钮固定果橙底＋深绿墨字/图标，对比度约4.61。按下底色`#FF8B62`，保留深绿墨；不使用使文字变淡的整组透明度。次级按钮用薄荷底＋深绿墨。文字链接用深橙，不以亮橙小字承载关键信息。

选中卡同时使用深橙2px边框、明确的勾选图标与“已选”辅助语义；亮橙边框可作装饰，但不能是唯一状态线索。AI角标使用柚黄底＋深绿墨，不与官方标识混用。

tokens为可复用的语义变量。不得从原图取相近像素色另建每页颜色。对比计算清单见[contrast-report.json](../../../../assets/design/柚子创作社/v1.0/contrast-report.json)；最终字体、真实照片和系统渲染仍需实机检查。

## 2. 字体与文字

字体分三个角色：展示标题用圆润、宽字面的粗黑体感；交互正文用宿主可用的系统无衬线；数量、时长、金额使用同一正文的等宽数字能力。使用系统字体优先，不把本机微软字体文件或生成图中的字形当作可随产品分发的授权字体。

字体序列是实现意向：`PingFang SC, Microsoft YaHei, Noto Sans CJK SC, sans-serif`，每个终端使用实际可用字体，不保证完全同字形。圆润感主要由字重、字号、短句和留白表达；若后来选用专有圆体，先确认授权并单独版本化，不阻断主流程。

| 角色 | 字号/行高 | 字重 | 规则 |
| --- | --- | --- | --- |
| 首页展示标题 | 28/38 | 700 | 最多两行，按语义断行，不压成小字 |
| 页面标题 | 22/30 | 700 | 正式业务页使用 |
| 分区标题 | 18/26 | 700 | 图片素材、试试这些方案 |
| 卡片标题 | 16/24 | 600 | 方案名最多两行，可点详情看全 |
| 正文/按钮 | 16/24 | 400/600 | 价格、权益、错误不能缩小 |
| 次级说明 | 14/21 | 400 | 风格说明、作者、预计区间 |
| 标签/图注 | 12/18 | 500 | 非唯一关键说明；点击热区另行扩展 |

默认不小于12逻辑像素，金额与关键操作不得仅用图注字号。交易、授权和错误不使用手写体。商品名称/作者名支持中英文、长名与表情，不截断唯一身份信息；长说明展开查看。

## 3. 布局基准

- 基准375逻辑宽，页面左右16，内容宽343；屏宽320–430作设计覆盖，宽屏居中限制内容宽560，不将每个控件等比拉大。
- 间距标尺：4、8、12、16、20、24、32、40。元素内8/12，卡片内16，分区24，顶部品牌与主标题16。
- 卡片圆角16，照片内图圆角12，标签圆角8，主按钮胶囊999；底部弹层圆角24。圆角按语义复用，避免一页多套随意数值。
- 主按钮最小高52、横内边距20；次级44；图标/小链接的实际点击热区至少44×44。按钮文字可换行并增高，不能强制单行裁切。
- 单列列表卡间距12，图片缩略图间距8。四图行仅在每张仍可点开且图注清楚时使用；窄屏/放大文字可改两列，不强求一屏全展示。
- 375基准中16逻辑像素对应32rpx。只把弹性布局尺寸按750设计宽换算；字号、最小触达和最小控件高度必须单独保证，不能因320屏宽的rpx缩放降到下限以下。

原生顶部状态区、胶囊区与底部安全区使用平台/设备实际测量值。本规范不固定状态栏高度，不重画平台胶囊，不在相机或支付原生页叠自制装饰。

## 4. 照片印样：品牌特征

首页最多3张商品照片作为印样，分别说明整体、角度、细节。白色窄边6、轻阴影、旋转角建议-4°/2°/5°，只旋转视觉照片，不旋转点击热区和标签正文。输入后的真实照片应替换示例；空白用户看到明确“示例”而非伪造其商品。

首页可有一条柚黄短划线、少量果橙手绘短线。完成页可有一次浅薄荷标题带。每屏最多一个主要装饰区域；纸纹/印章不叠在价格、正文、商品细节或操作上。列表与付款页不使用歪斜卡片和大面积撕纸边。

作者标识是头像/作者名/来源链，不伪造“认证印章”。官方仅用于平台官方方案；审核通过不等于商业认证或质量保证。生成图中的任意印章文字不得直接作为正式资质声明。

## 5. 图片与视频

商品原图用于选片/身份核对时完整显示，容器可留边，不裁掉包装、文字或关键结构。方案样例封面可用裁切，但进入详情和结果预览应完整展示；样例标注“方案样例”，不能假装是用户的成品。

方案横向作品卡左侧样例图在375宽下建议120宽、4:5；右侧信息至少能显示方案名、来源/作者、效果/节奏、图数与时长。320宽或文字增大时切上下结构，不把信息挤成不可读细字。卡片主样例优先真实授权素材；基线中的蓝色榨汁杯只作设计示例。

视频结果默认9:16完整画幅，`contain`语义，不为了让四图与按钮同屏而剪成方形。允许页面滚动；可在列表显示裁切封面，但播放器必须完整。播放默认用户触发，有声内容不自动外放；时长来自交付媒体而非固定写12秒。AI标识、字幕和播放器控制不互相遮挡。

UI奶白与橙色不强制进入生成素材的风格。素材采用用户选择的10套官方/社区方案，商品真实颜色不能为了呼应UI改成橙色。

## 6. 图标、线条与层级

采用简单圆端线性图标，常用24、线宽2；图标旁有文字，不能只靠含义不清的相机/印章引导。选中与未选中来自同一图标体系；底部三栏图标分别表达拍照、方案作品、素材。

普通卡片1px轻边线，选中2px深橙描边；不要只通过阴影表达交互。阴影只用在照片印样和浮层，内容卡默认轻边线。层级：内容0、吸顶10、固定行动20、遮罩40、弹层50、轻提示60；原生系统弹层由宿主管理，不试图覆盖。

## 7. 动效

按下反馈120ms，局部状态变化180ms，底部弹层进入240ms；曲线`cubic-bezier(0.2,0,0,1)`。印样初入最多一次轻位移/淡入，不能循环晃动。制作等待只表现真实阶段，无进度估计时不播放假百分比。减少动态效果偏好或性能不足时关闭位移、转场与闪烁，仍保留文字状态和按钮反馈。

## 8. 页面风格分配

| 场景 | 可用特征 | 应收敛的部分 |
| --- | --- | --- |
| 拍照首页 | 三张印样、短划线、果橙主行动 | 不放大面积功能介绍或复杂编辑器 |
| 方案社区 | 作品卡、作者行、官方/AI标签 | 列表保持正直对齐，无瀑布流错位影响比较 |
| 确认/付款 | 奶白、白卡、清晰金额与清单 | 不放印章、转圈庆祝、营销倒计时 |
| 生成进度 | 真实阶段、商品缩略图、温和状态色 | 不伪造百分比或以动画替代状态 |
| 素材结果 | 薄荷标题带、媒体大图、素材印样 | 不裁视频，不强制分享 |
| 异常/售后/权限 | 标准卡、原因与恢复动作 | 不用插画掩盖问题，不把错误写成空泛情绪 |
