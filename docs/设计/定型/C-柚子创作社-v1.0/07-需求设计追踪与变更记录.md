## 3. 后续变更记录格式

记录版本、日期、触发原因、用户指示或设计依据、涉及DF/组件/页面、tokens差异、业务影响、验证证据与回滚参照。没有业务变化不重编号需求；业务范围变化先更新PRD/追踪矩阵，再同步页面规格。

当前不可变的用户选择证据与原始图摘要保存在基线清单。后续出高保真图时保留新旧图和变更说明，不把新图覆盖成“原始C稿”。
