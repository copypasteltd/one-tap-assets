# 00 · 设计定型总纲

基线：`YPCC-DS-C-1.0.0`。日期：2026-10-27。用户决策原文：“选用方案 C”。适用需求：一品成片 v3.0；适用核心载体：支付宝小程序、抖音小程序。

## 1. 定型结论

选用C「柚子创作社」：奶白底、果橙行动色、深绿墨文字，浅薄荷与柚黄作有限辅助。品牌特征是“自己的商品照片像一套可以取走的创作印样”，社区通过作者行和清楚的来源标识表达可信的创作关系。

这一方向服务个体商家快速自助出素材的目标。它应亲近、有活力、作品优先，同时保持付款、进度、隐私与保存状态清楚。产品名称为“一品成片”；不改名为“柚子创作社”。

## 2. 设计目标与固定原则

1. 首页立即说明“拍3–5张商品照，选方案，得到整套图片和视频”，不要求写卖点、提示词或剪辑。
2. 商品照片是主要视觉。照片的结构、颜色、包装和品牌不可为统一UI色调而改变。
3. 每个页面/状态只有一个主行动。识别结果摘要、官方/社区来源和完整产出清单应就近可见。
4. 社区是预设方案的发现与复用，普通买家不被带进编辑器；作者看不到买家照片和订单。
5. 操作、交易与状态优先采用清晰的系统字体，装饰只在首页照片印样与轻量完成标识使用。
6. 先明确清单、效果、金额和期限，再由用户主动付款。权限按动作请求，未知结果不能伪装成功。
7. 支付宝与抖音同等核心。共用产品语言和视觉，宿主导航、登录、权限、支付和保存尊重各自原生能力。

## 4. 与原始图的关系

原图是用户选择的视觉证据，按原字节保存。正式实现采用以下修正，均不改变C方向：

| 原图表现 | 正式定型 |
| --- | --- |
| 果橙上白色小字/图标 | 果橙 `#FF7948` 上用深绿墨 `#263B32`，正文对比度约4.61；白字仅在足够深的色块上 |
| 视频封面接近方形 | 默认完整9:16预览；紧凑卡只裁封面，进入播放器不裁内容；页面允许滚动 |
| 4图＋1条12秒视频 | 仅为清新日常示例；按已选方案/变体动态显示3–5图及实际时长 |
| 手写标签和较多纸纹 | 只在首页印样/合法装饰使用；操作、价格、错误、权限无手写体 |
| 方框/勾选等图标存在绘图自由度 | 统一线宽、明确选中与文字；作者、官方、AI标识各有独立语义 |
| 手机外框、外部背景色块、板头说明 | 均属于展示板，不进入小程序实际内容 |
| 普通完成页上额外返回箭头 | 根页不放假返回；素材详情才有返回及清晰的我的素材归属 |

照片印样不等于把整页做成纸张拼贴。重要内容、点击区域和列表信息保持正直对齐，装饰不干扰滚动、点击和识别。

## 5. 来源优先级

业务与权益以 [v3主需求](../../../01-产品需求PRD.md) 和其余4份主文档为准；本套规范确定视觉与交互表达。视觉数值以本规范和`design-tokens.json`为准；页面/组件责任以注册表为准；原始图只在这些规则未涉及的风格细节上作参照。

发现文档与JSON不一致时先记录差异，更新同一版本内尚未交付的规范并重新核验；已发布/交付版本不得静默改文件。不能通过“还原设计稿”为由省略确认付款、平台权限、失败退款、官方10套/14变体或社区数据隔离。

## 6. 版本与留存

用户选择的原始图不可覆盖；新的视觉修订另存版本。大改方向升主版本，新增组件/页面规格升次版本，文字修正或不改变语义的数值修补升补丁版本，并更新变更说明、tokens、摘要和归档。当前`v1.0`目录为首个完整基线，对应语义版本`1.0.0`。

当前入口位于`assets/design/current.json`。开发开始前读取它及本目录README；旧五方案画册保留比较用途并标注C已选定，先前推荐B的意见仅作历史记录。未经新的用户选型，不自动恢复A/B或把其他方向混入默认主题。
