## 产品承诺与载体

商家在支付宝或抖音小程序拍商品，系统识别“这是什么、有哪些可见特征”，用户选一个官方或社区方案，系统全自动制作完整媒体清单，用户直接保存相册。网页Plus深化精细编辑、品牌/批量/复杂方案，基础体验不依赖它。

推荐底部三个入口：“拍照制作”“方案社区”“我的素材”。创作者在方案社区/个人页有“创建预设”“我的预设”，普通买家不必进入编辑器。两端业务一致，登录/拍照/上传/支付/相册按平台适配，不把网页套壳当完成。

## 用户实际看到的流程

1. 拍照制作：提示正面整体、斜侧、真实细节，拍摄/相册选择3–5张；仅在需要时请求权限。照片无效说明具体原因，合格部分保留。
2. 自动识别：显示“正在识别商品和可见细节”，分析完成给一行摘要，例如“已识别：米白色托特包 · 双提手 · 外侧口袋”。不弹出必须逐项确认的商品表。可选“识别有误”是纠错入口，正常用户可直接继续。
3. 方案选择：先过滤照片/商品锁和能力条件，再推荐官方/社区。卡片展示风格样例、节奏、图数/秒数、作者、价格与预计区间；同一风格可选“图文展示”“AI生活场景”“AI单镜/多镜讲解”等效果，清晰说明AI演绎/声音。样例不是本人结果，不展示模型/seed必选项。
4. 一键制作：系统自动形成商品锁、事实脚本、精确时间轴、参考/实际模型计划；确认页只给清单/效果/声音/金额/期限，收费时主动付款。后台生成图片/参考/片段或整片，保护原声并加字幕/配乐/商品卡/封面后验收。用户不编辑脚本或逐镜审核。
5. 我的素材：按清单显示封面、角度、细节、海报和短片，另有文案复制。用户点“保存整套”“只存图片”“只存视频”或保存单项。

用户创作输入是照片和方案选择。必要登录/隐私/付款/相册授权仍由用户完成，服务不能自动替用户同意。服务端制作可在小程序退出后继续，相册写入按客户端生命周期，不能承诺持续后台保存。

## 多模态补齐什么

系统维护一份用户无需填写的商品档案：商品类别、建议商品名、主/辅色、图案、外形、可见结构/纹理/细节、照片视角/主体位置、可读标签、候选展示特征、质量/跨图冲突、适配方案。档案用于决定文案写什么、哪个细节放大、哪个方案适合，不仅仅用于给照片贴标签。

示例仅用于说明字段，不是真实识别结果：

```json
{
  "schema_version": "1.1",
  "example_only": true,
  "category": {"value": "托特包", "status": "observed", "source_asset_ids": ["photo-1", "photo-2"]},
  "suggested_name": "米白色双提手托特包",
  "observations": [
    {"field": "color", "value": "米白色", "status": "observed", "source_asset_ids": ["photo-1"]},
    {"field": "structure", "value": "双提手", "status": "observed", "source_asset_ids": ["photo-1", "photo-2"]},
    {"field": "detail", "value": "外侧口袋", "status": "observed", "source_asset_ids": ["photo-3"]}
  ],
  "hypotheses": [{"field": "material", "value": "可能为织物", "copy_allowed": false}],
  "unknowns": ["精确尺寸", "纤维成分", "售价", "产地", "防水性能"],
  "safe_copy_candidates": ["双提手设计", "外侧口袋细节", "米白色外观"]
}
```

直接可见且证据通过校验的信息可自动用于成品，不把用户重新拉回长表单。材质观感可以记为候选，但精确成分/尺寸/功效不能凭照片猜定。OCR识别到包装写“100%棉”也只证明图片中有这段标注，不证明内容真实；价格/认证/功效不自动作为当前有效事实。低置信/冲突字段留未知，用其他可见特征补足文案。

模型自报高置信不等于正确，必须结构校验、证据归属、跨图一致性和字段政策校验。类别不明可用宽泛描述，完全不可用输入才补拍；视觉调用失败有限重试后在收费前明确失败，不虚称识别完成。文案服务故障但已有有效档案时，规则模板仍可继续制作。

技术候选是经样例评测的视觉LLM，模型/供应商暂不锁死。阿里云官方说明支持从视觉输入抽取商品信息并输出JSON；不同模型/模式的结构保证须实测，应用仍独立验证字段，不能把格式合法当事实准确。[视觉理解官方说明](https://help.aliyun.com/zh/model-studio/vision-model)、[结构化输出说明](https://help.aliyun.com/zh/model-studio/qwen-structured-output)。

## 官方保底10套方案

| 方案 | 视觉方向 | 镜头节奏 | 交付媒体 |
| --- | --- | --- | --- |
| 极简纯净 | 浅色留白、突出主体 | 慢，10秒，整体→角度→细节 | 4图＋1短片 |
| 自然手作 | 暖色纸感、自然质感 | 舒缓，15秒，整体→角度→两处细节 | 5图＋1短片 |
| 轻奢细节 | 深色、克制字体 | 中慢，15秒，细节长停留 | 5图＋1短片 |
| 清新日常 | 明亮、柔和彩块 | 轻快，12秒，均匀四段 | 4图＋1短片 |
| 食欲快闪 | 暖色近景、实拍层次 | 快，10秒，短切和停留交替 | 4图＋1短片 |
| 家居留白 | 自然空间与留白 | 舒缓，18秒，长停留轻平移 | 5图＋1短片 |
| 特征卡片 | 信息卡片与可见细节 | 分段，15秒，每段一个特征 | 5图＋1短片 |
| 色彩撞击 | 高对比图形、原商品色 | 快，8秒，短切转场 | 3图＋1短片 |
| 上新叙事 | 连续章节、统一图文 | 渐进，20秒，初见到细节再整体 | 5图＋1短片 |
| 竖版种草 | 竖版大图、短标题 | 轻快，15秒，有序图文 | 3图＋1短片 |

方案定义生产合同，并按执行变体冻结能力、声音/人物/参考、实际模型/费率、原生与交付规格、完整清单、时间轴、质量/修复/时限和服务价。当前 [v3配置](../../assets/presets/presets.v3.json) 含10套/14变体，全部设计/禁售；不以来源391条或JSON数量冒称可用。

10套各保留一个图文展示变体；增加轻奢细节·AI质感展示（15秒/5图）、清新日常·AI生活场景（12秒/4图）、竖版种草·AI单镜讲解与AI连续多镜（各15秒/3图）。买家选效果，后台分别走原图、逐镜或参考整片；三路线/四生成变体均为完整v3的P0。

AI场景可创造厨房/工位等周边环境，但瓶装不能变杯装/礼盒、包袋不能增加口袋/附件。平台提供准入AI人物/声音，用户无需真人照；人物讲解是广告演绎，不伪装已购买/长期体验。照片机位不足在收费前补拍或明确改选，不能收费后静默换成照片卡片。

以“自然手作”为例，照片经识别后自动生成：商品主图、角度图、两张真实细节图、竖版海报、15秒竖版短片，另给可复制文案。最少3张照片时细节可从清晰实拍裁出，不创造新背面/内里；同一图安全复用必须符合方案公开样例和质量门槛。抠图不可靠按既定留背景方案完成，不改变商品颜色和结构。

信息卡不用不存在的参数凑字数，食品方案不编成分/保质期，叙事方案不虚构真实开箱过程，种草方案不伪造用户评价。预设的节奏由镜头停留/切换/字幕进入决定，已授权音乐可选，无音乐时也能表达节奏。

## 社区如何自行拓展

社区用户可以是商家、设计者、服务商或其他创作者，不要求所有买家都成为作者。平台提供安全的可组合渲染模块和同一配置格式，官方与社区方案共存。

创作流程：新建/允许派生 → 组合已准入叙事/运镜/Look/人物/声音/字幕、版式和输出 → 选择允许的执行变体 → 自有/授权样例 → 各变体清单/质量/基准/许可/成本 → 明确许可 → 审核发布。基础编辑可在两小程序独立完成；AI组件只在其能力已准入后开放，Plus深化复杂时间轴。普通买家用同款不需创建这些配置。

普通用户流程：看公开样例/作者/版本 → 收藏/用同款 → 套用自己的档案 → 按明示报价制作 → 保存相册。推荐可以用商品类别和特征，不能把买家照片发给社区作者。作者公开的是方案配置和单独授权样例，商品档案、买家原图、订单、下载链接一律私有。

首版机制含发现/筛选、收藏、使用、派生/署名、受控发布、审核/版本、举报/暂停/申诉。评论、关注、消息、榜单营销、作者付费模板和分成/提现不作为P0依赖。P0暂按方案免费分享、平台按制作服务计费，具体价和免费额度待成本验证。

派生必须遵守父方案及资源许可，署名和来源链保留。社区配置不得执行脚本、任意外链或未经准入模型。发布前审核样例和许可是社区工作，不变成每个买家订单的人工制作步骤。更新需新版本再审；普通下架不毁旧合同，强制禁用影响旧单时有通知与退款/补偿。

## 相册、支付与上线证据

相册保存必须是用户点击后按平台能力授权执行。保存5/6项时明确剩余失败项；只续存未完成项，不重新渲染/收费。回调未知不能冒称成功，也不能保证系统相册存在可查询哈希的绝对去重能力。文案复制与媒体保存分开，手机无需下载解压ZIP。

抖音官方视频保存要求本地路径及用户授权；支付宝境内对应接口/版本需单独真机确认，不能拿Alipay+同名接口作境内证明。[抖音视频保存](https://developer.open-douyin.com/docs/resource/zh-CN/mini-app/develop/api/media/video/tt-save-video-to-photos-album)。两端能力分别验收，不因一端成功就宣称另一端完成。

两端用各自批准的支付/订单路径；Vibe Pay网页能力不自动等于小程序已开通。[Vibe Pay](https://aipay.alipay.com/docs/vibe-pay.html)。具体审核条件按上线时正式文档复核，本文不代表任何平台资质已经获批。

进度展示排队、准备参考、生成画面/视频、后期、验收等真实阶段；离页后云端继续，临时文件/相册队列只在允许的客户端生命周期工作。原图/逐镜/整片按已购变体的不同预计区间/硬截止，不能一律显示“120秒完成”；失败给可理解原因与原合同退款/恢复入口。

验收证据包括真实视觉/商品锁、三路线和四生成式调用、10套/14变体各30组共≥420次、独立识别/高危负例/声音集、社区隔离、四类真机相册/交易与5名商家无代教自助试用。全部待执行，见 [验收计划](../05-验收测试与实施计划.md)。
