```powershell
./scripts/bootstrap-native.ps1 -Postgres
./scripts/run.ps1 exec tsx scripts/dev-setup.ts
./scripts/run.ps1 dev:api
# 另开本项目终端运行独立 Worker；真实交易/模型开关默认关闭

# 再开本项目终端运行独立回收器；不依赖制作 Worker 的 finally

# 媒体物理删除与到期维护也有独立原生进程
./scripts/run.ps1 dev:media-maintenance
```

首次启动脚本在本项目 `runtime/` 准备原生 Node/PostgreSQL、创建开发数据库和自签名 HTTPS 证书，凭证只保存在 `.env.local`。API 默认位于 `https://localhost:3100`；证书仅用于本地开发。测试命令为 `./scripts/run.ps1 test` 和 `./scripts/run.ps1 test:integration`；集成测试在本项目数据库内创建独立随机 schema，并只清理本次 schema。原生媒体测试需要 PATH 内可用的 FFmpeg/ffprobe。
