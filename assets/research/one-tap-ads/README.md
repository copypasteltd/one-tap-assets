## 统计口径

391条按原始ID计数。相同执行参数比较时，先递归规范化对象键顺序，再比较脚本风格、形态、Look、运镜和compose，得到385组；加上scriptHint后为391组。6对参数相同但叙事创意不同，不等同于6个完全重复方案，也不能把385组计作385种渲染引擎。

视频取样使用固定时间窗和每秒取样；没有自动识别真实剪切点。公开联系表和输入图/九宫格对照整理至[media](media/README.md)，记录原来源与SHA；完整本地分析留在忽略的runtime目录。它们是上游研究缩略图，不是一品成片生成结果。样例价格、销量、功效、长期体验不作为新商品事实。

## 复现

在本项目根目录执行以下命令，使用已有原生Node/Python和隔离研究依赖；不需要Docker/WSL，也不会启动网页/Electron或提交付费模型生成：

```powershell
node scripts/提取仓库方案.mjs
python -X utf8 scripts/生成仓库方案目录.py
python -X utf8 scripts/生成云端方案蓝图.py
```

导出脚本检查固定提交，以Vite SSR读取声明式模块，禁用HMR/监听并在finally关闭服务。生成目录脚本使用既存视频证据，不重新抽帧；视频抽帧流程与限制见案例深析。执行草案中的时长/尺寸是本产品合同，不证明供应商现有模型已经支持或达到对应画质。
